# Hamiltonian Path / Cycle の実装解説

[使用法に戻る](../hamiltonian.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/hamiltonian.hpp)

## 部分集合 DP

`dp[mask]` は、訪問した頂点集合がちょうど `mask` の路について、
終点にできる頂点を表すビット集合です。
`incoming_[v]` は頂点 `v` に辺を持つ直前の頂点候補のビット集合です。

始点を指定しない場合、すべての頂点について `dp[1<<v]` に `v` を登録します。
始点を指定した場合は、その1状態だけを初期化します。
`mask` に含まれる各頂点 `v` について、
`dp[mask ^ (1<<v)] & incoming_[v]` が非零なら、
`v` を最後に追加できるため `dp[mask]` に `v` を登録します。

1回のビット積で直前の全候補をまとめて判定するので、
遷移は $O(n2^n)$ 時間、DP の領域は $O(2^n)$ です。
最大24頂点に制限し、各状態を32ビットで保持します。

## 路と閉路の復元

路は全頂点の状態から終点を1つ選び、終点指定がある場合はその頂点に限定します。
終点を訪問集合から外し、残りの状態の終点集合と現在頂点の入辺を交差させることで
直前の頂点を復元できます。最後に頂点列を反転します。
各段階で有効な前状態を選べるため、状態ごとの親配列は不要です。

閉路では始点を固定して同じ DP を使い、全頂点の状態の終点候補のうち
始点への辺を持つものだけを残します。始点は閉路のどの頂点にも選べるので、
既定では頂点0に固定します。

重複辺は通常の遷移に影響しません。ただし無向2頂点の閉路だけは辺の使い回しを
避ける必要があるため、辺数を2で打ち切って別途保持します。
1頂点では始点への辺、つまり自己ループの有無を通常の閉路判定で確認できます。

## 確認方法

小さいグラフで全頂点の順列を列挙し、路・閉路の存在判定と比較します。
復元した列が全頂点を1回ずつ含むこと、隣接する頂点間の辺、指定端点、閉じる辺も検証します。
有向・無向、自己ループ、多重辺、非連結、空・1頂点・2頂点と、
隣接リスト・辺リスト・逐次追加の各構築方式を確認します。
