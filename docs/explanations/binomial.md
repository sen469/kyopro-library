# Binomial の実装解説

[使用法に戻る](../binomial.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/binomial.hpp)

## 目的と基本原理

二項係数を毎回積で計算せず、階乗とその逆元を再利用します。素数pでn<pなら $\binom nk=n!/(k!(n-k)!)$。合成数では分母が逆元を持たない場合があるため、素数冪ごとにpの因子を分離する別方式を使います。

## 内部データ

`binomial/dynamic_binomial` は `fact_` と `inv_fact_` を保持し、違いは法がコンパイル時か実行時かです。任意法版は `bins_` に `prime_power_binomial` を持ち、各 $q=p^e$ に対し `p_,q_,exponent_,periodic_,fact_` を管理します。

## 処理の流れと不変条件

素数版の `ensure` は階乗を延長し、末尾の逆階乗を累乗で求めて後ろから埋めます。任意法版は $v_p(n!)=\sum_{k\ge1}\lfloor n/p^k\rfloor$ でpの指数を数えます。例えば $\binom42=6$ を法8で計算すると、2の指数1と奇数部分3に分けて復元できます。

n<qでは各整数からpを除いた積を保持し、n>=qになると `build_periodic` でpの倍数を除いた1周期の表に切り替えます。`fact_without_p` が周期積とn/pへの再帰で残りを求め、逆元の存在する部分だけ割ります。指数がe以上なら0。最後に互いに素な素数冪の剰余を `crt` で統合します。

## 計算量の根拠

素数版は延長幅dに対し $O(d+\log p)$、前計算済みなら取得 $O(1)$。任意法版は初期因数分解が試し割りで $O(\sqrt{mod})$、表は各素数冪で最大 $O(q)$ 空間です。周期表構築後の再帰深さは $O(\log_p n)$ で、各段に累乗があるため保守的には $O(\log_p(n+1)\log(n+1)+\log q)$ 程度を見込み、素数冪の個数分が必要です。`fact(n)` は別の通常階乗表をnまで延長します。

## 改造時の注意点

素数版は法の素数性を自動検査せずn<法が必要です。任意法版でも大きな素数冪の周期表はメモリに収まりません。戻り値型Tを変えても内部の法はintです。法1、範囲外kを返す経路と、負のnが許されない経路を区別します。

## 改造後の確認

Pascal の三角形との比較、k=0/n、kの範囲外、法1・素数・素数冪・複数素因数を確認します。周期表への切替前後で同じ入力の結果が変わらないことも確認します。
