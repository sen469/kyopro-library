# Ternary Search の実装解説

[使用法に戻る](../ternary_search.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/ternary_search.hpp)

## 目的と基本原理

整数区間の谷型関数の最小点、または山型関数の最大点を探します。例えば $f(x)=(x-3)^2$ なら3が最小です。2点の値を比較して最適点のない側を約3分の1除去します。

## 内部データ

`first,last` は非空の半開区間、`middle1,middle2` は三等分点です。`Compare` の既定値は小さい値を良いとし、`std::greater` で最大化になります。整数の距離計算は binary_search の補助関数を共有します。

## 処理の流れと不変条件

右の評価値がより良ければ左端を `middle1+1` へ進め、そうでなければ右端を `middle2` にします。幅3以下では全候補を左から調べ、厳密に改善する場合だけ更新するため最適点が複数なら左側を選びます。除去側により良い点が存在しない形状が前提です。

## 計算量の根拠

範囲が一定比率で縮むため評価回数は $O(\log W)$、補助空間 $O(1)$。評価関数の費用を掛けて見積もります。

## 改造時の注意点

最適区間以外に平坦部分がある弱い単峰性だけでは、2点が等しいときの切り捨てが安全とは限りません。厳密に改善して最適区間に達し、その後厳密に悪化する形などを使います。多峰関数や浮動小数点区間には流用しません。

## 改造後の確認

幅1～3、端で最適、谷・山、最適値の平坦区間を全探索と比較します。例えば最適でない平坦部の後に改善する関数は前提違反として区別します。
