# Tree Diameter の実装解説

[使用法に戻る](../tree_diameter.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/tree_diameter.hpp)

## 目的と基本原理

非負重みの連結な木で最も長い単純路を求めます。任意の頂点から最遠点sを探し、sからの最遠点tへの道が直径になります。重み1の道 `0-1-2-3` なら両端0と3、長さ3です。

## 内部データ

`tree_diameter_find_farthest` は `stack,seen,parent,dist` を作り、開始点からの距離と最遠点を返します。`tree_diameter_result` に直径長・両端・頂点列と、中心を表す `center` を格納します。

## 処理の流れと不変条件

木では各2頂点間の道が一意なので、重み付きでも DFS の累積で距離が決まります。非負重みでは任意点からの最遠点を直径の端として選べるため、2回目の探索で最長路を得ます。2回目の `parent` をtから逆にたどり、sからtの順に戻します。

## 計算量の根拠

木の辺数はN-1なので、2回の探索と経路・中心の復元は $O(N)$、空間も $O(N)$ です。探索は明示的なスタックを使います。

## 中心点・中心辺

`build()` 内で選んだ直径の重み付き中点を探し、結果の `center` に保存します。
2回目の探索で得た距離配列を再利用し、直径経路を始点側から走査します。
各頂点について始点側の距離 `d` と終点側の距離 `diameter-d` を比較します。
等しければその頂点が中心です。初めて始点側の距離の方が大きくなった場合は、
直前の頂点との辺の内部に中点があります。

距離を 2 倍したり整数型で直径を 2 で割ったりしないため、距離の倍算による
オーバーフローや奇数長の切り捨てを避けられます。
0重みの辺により複数の頂点が中点に重なる場合は、経路上で最初に見つかった頂点を採用します。

## 改造時の注意点

負重みを許すと2回最遠点法の根拠が崩れるため、木 DP など別の方法が必要です。等距離時の端点は走査順に依存します。

## 改造後の確認

空・1頂点・道・星・0重みの木を確認します。小さい木の全頂点対距離の最大値と、返った道の重み和を比較します。
中心については単位重みの木の全頂点の離心率を求め、その最小値を取る頂点集合と
返された中心点・中心辺の端点を比較します。重みで中点がずれる例、0 重みの連続、
整数型の最大値付近も確認します。
