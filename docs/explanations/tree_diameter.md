# Tree Diameter の実装解説

[使用法に戻る](../tree_diameter.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/tree_diameter.hpp)

## 目的と基本原理

非負重みの連結な木で最も長い単純路を求めます。任意の頂点から最遠点sを探し、sからの最遠点tへの道が直径になります。重み1の道 `0-1-2-3` なら両端0と3、長さ3です。

## 内部データ

`tree_diameter_find_farthest` は `stack,seen,parent,dist` を作り、開始点からの距離と最遠点を返します。`tree_diameter_result` に直径長・両端・頂点列を格納します。

## 処理の流れと不変条件

木では各2頂点間の道が一意なので、重み付きでも DFS の累積で距離が決まります。非負重みでは任意点からの最遠点を直径の端として選べるため、2回目の探索で最長路を得ます。2回目の `parent` をtから逆にたどり、sからtの順に戻します。空グラフは端点-1・長さ0です。

## 計算量の根拠

木の辺数はN-1なので、2回の探索と復元は $O(N)$、空間も $O(N)$。優先キューは使いません。

## 改造時の注意点

一般グラフの DFS 距離は最短距離でも最長距離でもありません。森では0を含む成分しか探索しません。負重みを許すと2回最遠点法の根拠が崩れるので木 DP などへ変更します。等距離時の端点は走査順に依存します。

## 改造後の確認

空・1頂点・道・星・0重みの木を確認します。小さい木の全頂点対距離の最大値と、返った道の重み和を比較します。
