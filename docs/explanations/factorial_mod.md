# Factorial Mod の実装解説

[使用法に戻る](../factorial_mod.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/factorial_mod.hpp)

## 目的と基本原理

素数pを法にした階乗を、0側またはp-1側の近い方から求めます。Wilson の定理 $(p-1)!\equiv-1$ より、nがp-1に近ければ短い末尾積の逆元からn!を得られます。p=7,n=5なら $5!\equiv -1/6\equiv1$ です。

## 内部データ

単発版は `right=p-1-n` と積を持ちます。バッチ版はクエリを0側の `left` とp-1側の `right` に分け、元のIDと距離を保存します。`factorial_mod_pow` は二分累乗です。

## 処理の流れと不変条件

nがp以上ならpを因数に含むため0。小さい側なら1からnを掛け、大きい側ならn+1からp-1の積を作り、フェルマーの小定理で逆元を計算して-1を掛けます。バッチ版は距離順に並べて前の積を再利用しますが、右側クエリの逆元は各回計算します。

## 計算量の根拠

単発は $O(\min(n,p-1-n)+\log p)$ の上界、追加空間 $O(1)$。Q件のバッチはソート $O(Q\log Q)$、両側最大距離までの積、右側件数Rについて $O(R\log p)$ が必要です。空間 $O(Q)$。

## 改造時の注意点

mod の素数性は実行時には検査しません。合成数では Wilson とフェルマーの逆元が使えないので、assert の変更だけでは対応できません。pの中央付近のnは依然線形時間となり、大きなpで常に高速とは限りません。

## 改造後の確認

0!、p-1、p、pを超えるn、同じクエリの重複、左右を混ぜたバッチを小さい素数の直接計算と比較します。
