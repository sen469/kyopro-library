# Rolling Hash の実装解説

[使用法に戻る](../rolling_hash.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/rolling_hash.hpp)

## 目的と基本原理

部分列を多項式の値で表し、部分文字列比較を定数時間に近づけます。値列 `[a,b,c]` のハッシュは $aB^2+bB+c$ を法で割った余りです。前半の多項式を引けば任意区間を取り出せます。ただし同じハッシュでも同じ列とは限りません。

## 内部データ

`base_` が底B、`pow_[k]` が $B^k$、`hash_[i]` が先頭i要素のハッシュです。法は $2^{61}-1$、乗算は `unsigned __int128` で行います。文字列は unsigned char に1を足し、整数列は `value` で剰余へ写します。

## 処理の流れと不変条件

構築は `hash[i+1]=hash[i]*B+value[i]`。`get(l,r)` は $H[r]-H[l]B^{r-l}$ を法で正規化します。`concat` は左側を右の長さだけずらして加算します。`same` は長さも比較し、`lcp` は等しい接頭辞長について二分探索します。

## 計算量の根拠

構築・空間 $O(N)$、区間取得・結合・同一区間判定は $O(1)$、LCP は $O(\log N)$。比較の正しさは衝突がないことに依存します。

## 改造時の注意点

底と値の符号化が違うオブジェクト同士のハッシュは比較できません。既定の底は固定であり乱数化されません。底1は許容されても順序情報を失います。整数列では符号なし変換と剰余による衝突もあるため、絶対に誤判定できない処理には直接比較などが必要です。

## 改造後の確認

空区間、全区間、同じ文字の連続、別の底、連結後の直接構築との一致を確認します。LCP と部分列比較は小さい入力の直接比較で確認しますが、テストだけで衝突不存在は証明できません。
