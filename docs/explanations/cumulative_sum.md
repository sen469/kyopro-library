# Cumulative Sum の実装解説

[使用法に戻る](../cumulative_sum.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/cumulative_sum.hpp)

## 目的と基本原理

静的な多次元配列の直方体和を、原点からの和の足し引きで求めます。2次元では右下の累積和から上側と左側を引き、二重に引いた左上を戻します。例えば `[[1,2],[3,4]]` の右下1セルは $10-3-4+1=4$ です。

## 内部データ

`values_` は元配列、`data_` は各軸に長さ1のゼロ境界を加えた累積表、`sizes_` と `strides_` は平坦化した座標の配置を表します。`data_[r]` の意味は各軸 $[0,r_i)$ の和です。

## 処理の流れと不変条件

`rebuild` は値を全軸1ずつずらして置き、その後各軸方向に累積します。`sum` は各座標に左端か右端を選ぶ $2^D$ 個の組合せを巡回し、左端を選んだ軸数の偶奇で加減します。包除原理により欲しい直方体だけが1回残ります。

## 計算量の根拠

次元をD、累積表サイズを $P=\prod_i(n_i+1)$ とすると構築・`set` は $O(DP)$、区間和は $O(D2^D)$、空間 $O(P)$。`set` は差分更新ではなく毎回全表を再構築します。`all_sum` も `sum` を呼びます。

## 改造時の注意点

足し引きが整合する型を使い、総和の桁あふれに注意します。`min` のような逆演算のない集約には置換できません。多数の点更新が必要なら多次元 BIT/セグメント木等に切り替えます。次元増加で $2^D$ と表サイズが急増します。

## 改造後の確認

1次元との一致、各軸の空区間、境界0とサイズ、負数、`set` 後の全範囲を愚直な多重ループと比較します。
