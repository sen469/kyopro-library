# Run Length Encoding の実装解説

[使用法に戻る](../run_length_encoding.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/run_length_encoding.hpp)

## 目的と基本原理

隣り合う同じ値を `(値,長さ)` にまとめます。`aaabbac` は `(a,3),(b,2),(a,1),(c,1)` となります。離れた同値は統合せず、元の順序を保存します。

## 内部データ

`current` が現在のまとまりの値、`count` が連続数、`res` が確定したまとまりです。イテレータ版を本体とし、コンテナ版は begin/end を渡します。

## 処理の流れと不変条件

最初の要素を取り出し、以降が `current` と同じなら個数を増やします。違えば現在のまとまりを確定して新しい値から開始します。ループ終了後の最後のまとまりを必ず追加し、空入力は先に返して逆参照を避けます。

## 計算量の根拠

各要素を1度比較するため $O(N)$。出力のまとまり数をKとして空間 $O(K)$ です。値のコピーや比較が高価ならその費用が加わります。

## 改造時の注意点

個数は int なので非常に長い入力では型変更が必要です。長さの合計や復元を追加する場合も同じ型を揃えます。全出現回数の集計やソート後の圧縮とは違う処理です。

## 改造後の確認

空、1要素、全部同じ、全部違う、末尾だけ値が変わる例を確認します。出力を展開して元列と一致し、隣接する出力の値が異なるか確認します。
