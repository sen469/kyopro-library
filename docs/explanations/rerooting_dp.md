# Rerooting DP の実装解説

[使用法に戻る](../rerooting_dp.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/rerooting_dp.hpp)

## 目的と基本原理

すべての頂点を根にした木 DP を、根ごとの再計算なしで求めます。木の各辺を切った片側の答えを両方向に渡せれば、どの頂点でも全隣接方向からの情報を合成できます。距離最大値なら、各隣接方向の高さに辺長を足して最大を取ります。

## 内部データ

`parent,order` は仮の根0からの探索順、`dp` は子側のみの答え、`parent_contrib` は親側から届く情報です。頂点状態がR、隣接方向の集約がMで、`f_ve` が辺を越える変換、`f_ev` が頂点での仕上げです。

## 処理の流れと不変条件

逆順の `order` で下から `dp` を計算し、正順で親側を伝播します。各頂点の `prefix/suffix` に隣接方向の累積を作り、子i以外の情報を `op(prefix[i],suffix[i+1])` で得ます。全体から値を引く必要がないため逆演算は不要です。各根で1回ずつ再 DFS する二乗計算を避けます。

## 計算量の根拠

各頂点で次数に比例する配列を構築し、次数の総和は2(N-1)なので、各コールバックが定数時間なら時間・空間 $O(N)$。大きい状態のコピー費用もコールバック費用に含めます。

## 改造時の注意点

連結な木が前提です。`op` は結合則と単位元を持つ必要があり、コードは隣接リスト順を保持します。非可換演算ならその順序が DP の意味に合うか確認します。親子の逆方向でも同じ辺IDを `f_ve` に渡すため、方向別情報を使う改造は ID/引数の設計も必要です。

## 改造後の確認

1頂点、道、星、辺の入力順を変えた場合を確認します。小さい木で各頂点を根に通常の DP を実行して比較し、頂点自身を二重に数えていないか確認します。
