# ACL Math の実装解説

[使用法に戻る](../../atcoder/math.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/math.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

剰余累乗・逆元・中国剰余定理・床和をまとめたヘッダです。各処理は単純な繰返しを、二分累乗や Euclid 型の縮小へ変えています。例えば $x\equiv2\pmod3$ と $x\equiv3\pmod5$ は $x\equiv8\pmod{15}$ にまとめられます。

## 内部データ

`pow_mod` は Barrett 還元器 `bt` と累積r、累乗中のyを使います。`inv_mod` は `internal::inv_gcd` へ委譲します。`crt` はここまでの解 `r0,m0` と新しい制約 `r1,m1` を保持し、常に $0\le r0<m0$ とします。

## 処理の流れと不変条件

### 累乗と逆元

`pow_mod` は指数のビットごとに掛け、yを二乗します。`inv_gcd` は Euclid の互除法と係数更新を同時に進め、$ax\equiv gcd(a,m)\pmod m$ を満たすxを返します。逆元はgcd=1のときだけ存在します。

### CRT

既存解を $r0+m0t$ と置いて新しい合同式へ代入します。$g=gcd(m0,m1)$ が $r1-r0$ を割らなければ解なしです。割れるならgで割って互いに素にした式を逆元で解き、法をlcmへ更新します。法が相手の倍数のときは剰余の一致だけで判定できます。

### floor_sum

$\sum_{i=0}^{n-1}\lfloor(ai+b)/m\rfloor$ を求めます。a,bのm以上の部分は等差数列の和として先に加算し、残りの格子点を数える向きを交換してmとaを入れ替えます。Euclid 法のように値が小さくなるため、n個を列挙しません。負のa,bは `safe_mod` と補正項で非負版へ移します。

## 計算量の根拠

累乗は $O(\log n)$、逆元と床和は互除法型で $O(\log m)$。CRT は制約ごとの gcd/逆元処理の合計で、法の最大値Bと制約数Kに対して $O(K\log B)$ の上界です。入力・出力を除く作業空間は定数です。

## 改造時の注意点

CRT のlcmは long long に収まる必要があり、失敗 `(0,0)` と法1の解を区別します。逆元は素数法でなくてもgcd=1なら使えます。floor_sum の内部は符号なし64ビットの剰余算術を使うため、任意精度の厳密和へ変更するなら演算型と負数補正を合わせて変更します。

## 改造後の確認

指数0・法1・負の底、逆元の存在/不存在、非互いに素の整合/不整合 CRT、空制約を確認します。床和は小さいnで負のa,bも含め数学的な床除算による全加算と比較します。
