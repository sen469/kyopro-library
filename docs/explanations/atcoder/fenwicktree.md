# ACL Fenwick Tree の実装解説

[使用法に戻る](../../atcoder/fenwicktree.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/fenwicktree.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

点への加算と区間和を、2進数で定まる部分区間に分解して処理します。内部の1始まり添字6は最下位の立ったビットが2なので、要素5～6の和を担当します。接頭和6は担当区間6と4を足せば得られます。

## 内部データ

`data[p-1]` は内部添字pの担当区間、`_n` は要素数です。公開APIは0始まりですが、`add` 内で1を足します。内部型Uは `internal::to_unsigned_t<T>` を使います。

## 処理の流れと不変条件

`add` は `p += p & -p` でその点を含む上位区間を更新します。接頭和は `r -= r & -r` で互いに重ならない右端側の区間を取り出します。`sum(l,r)` は接頭和rから接頭和lを引き、不要な部分を相殺します。

## 計算量の根拠

各ステップで添字のビット構造が進むため、加算・取得とも $O(\log N)$。配列はN個で空間・ゼロ初期化 $O(N)$ です。

## 改造時の注意点

`set` は存在しないので現在値との差を加算します。min等へ演算だけ置き換えても接頭和の引算が成立しません。符号なしの内部演算は整数オーバーフローの扱いを意識したものです。下限探索を追加するなら、累積値の単調性のため各値が非負であるなどの条件が必要です。

## 改造後の確認

先頭・末尾加算、負の加算、空区間、全体和、1要素を配列の直接集計と比較します。
