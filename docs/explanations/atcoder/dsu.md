# ACL DSU の実装解説

[使用法に戻る](../../atcoder/dsu.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/dsu.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

動的な連結成分を根付き木で管理します。2頂点が同じ成分に属する条件は根が等しいことです。`merge(0,1)` の後で `merge(1,2)` をすると、0と2の間に直接辺がなくても同じ根になるため連結だと分かります。

## 内部データ

`parent_or_size` の負値は根の成分サイズ、それ以外は親番号です。`_n` は頂点数。根以外にサイズの情報は置きません。

## 処理の流れと不変条件

`_leader` は根を見つけた後、通った頂点を直接根へつなぎます。`merge` は小さい成分を大きい成分へつなぎ、根の負のサイズを加算します。これで集合の要素は変えず、親経路だけ短くできます。同根なら何も変えず根を返します。`groups` は各頂点の根を求め、根ごとの配列に集めます。

## 計算量の根拠

サイズ併合だけなら高さ $O(\log N)$、さらに経路圧縮により各操作はならし $O(\alpha(N))$。空間 $O(N)$、初期化 $O(N)$。`groups` は全頂点分の根取得と出力構築が必要です。

## 改造時の注意点

辺数は記録しません。成分数を追加するなら同根の早期 return より後でだけ減算します。巻き戻しや永続化には、経路圧縮による広い書換えをどう記録するかが問題になるため、サイズ併合だけの方式も検討します。代表元の番号自体は意味的な最小頂点ではありません。

## 改造後の確認

同頂点の併合、重複併合、成分サイズ、空グラフの groups を確認します。小グラフの BFS による成分分割と比較します。
