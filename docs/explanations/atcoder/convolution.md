# ACL Convolution の実装解説

[使用法に戻る](../../atcoder/convolution.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/convolution.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

多項式積 $c_k=\sum_{i+j=k}a_i b_j$ を高速に計算します。係数のままでは全組合せが必要ですが、多数の点での値に変換すれば積は点ごとの積になります。NTT はこの評価と補間を素数法上で行い、丸め誤差を避けます。

## 内部データ

`fft_info` の `root/iroot` は2のべき乗位数の根とその逆、`rate2/rate3` は回転因子の更新表です。`butterfly` と `butterfly_inv` が変換、`z` は出力長以上の最小の2のべき乗です。

## 処理の流れと不変条件

入力をzまで0埋めし、両方を変換して各点を掛け、逆変換後にzの逆元を掛けます。十分な0埋めにより巡回畳み込みの折返しが起きません。2段をまとめる4基バタフライと2基の処理を使い分けます。片方の長さが60以下なら素朴な二重ループです。

`convolution_ll` は3つの固定素数で計算して CRT により符号付き64ビットの答えを復元します。`offset[diff%5]` は固定素数と64ビット剰余の組合せに合わせた補正で、一般的な任意法 CRT の係数ではありません。

## 計算量の根拠

出力長Lに対して NTT は $O(L\log L)$、空間 $O(L)$。素朴分岐は $O(NM)$。整数版は3回のNTTでも同じ漸近計算量です。

## 改造時の注意点

法はNTTに適した素数でzがmod-1を割る必要があります。`convolution_ll` は出力長 $2^{24}$ 以下かつ真の各係数が long long に収まる条件です。根・法・回転表・CRT補正は連動するので一部だけ差し替えないでください。関数名にfftとあっても実体は整数の NTT です。

## 改造後の確認

空入力、1係数、60/61付近、2のべき乗前後の出力長、負係数の整数版を愚直積と比較します。丸めのない方式でも整数範囲の制約は別に確認します。
