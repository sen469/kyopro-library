# ACL String の実装解説

[使用法に戻る](../../atcoder/string.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/string.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

suffix_array は各位置から末尾までの列を辞書順に並べた開始位置、lcp_array は隣接する接尾辞の最長共通接頭辞長、z_algorithm は元列の先頭と各位置からの共通長です。`aba` なら SA=`[2,0,1]`、LCP=`[1,0]`、Z=`[3,0,1]` になります。

## 内部データ

SA-IS の `ls` は接尾辞のL/S分類、`sum_l/sum_s` は文字ごとのバケット境界、`lms_map/lms` はLからSへ変わる位置です。`rec_s` は短くした問題です。LCP の `rnk` はSAの逆順序、`h` は再利用する一致長です。

## 処理の流れと不変条件

### 接尾辞配列

後ろから比較し、次の接尾辞より小さいものをS、大きいものをLへ分類します。LMS位置の部分列を並べ、`induce` で同じ先頭文字のバケット内に前の位置を誘導します。既知の後続接尾辞順からL側を前向き、S側を後ろ向きに埋めることで辞書順が定まります。LMS部分列を名前に圧縮して再帰し、その正しい順序でもう一度誘導します。小さい入力は素朴ソート、次に doubling へ分岐します。

### LCP と Z

LCP は隣接順位の接尾辞と比較します。開始位置を1進めると既知の一致長は少なくとも1短くした分を再利用できるので、hを1減らしてから必要な分だけ延ばします。Z は最も右まで一致している区間の内部では既知のZを切り詰めて使い、右端外だけ新しく比較します。どちらも同じ文字を無駄に比較し直さない仕組みです。

## 計算量の根拠

上限付き整数列の SA-IS は $O(N+upper)$、文字列は固定文字種で $O(N)$。一般 vector 版は座標圧縮のソートで $O(N\log N)$。LCP とZは一致右端の前進回数を使うならし解析で $O(N)$、空間も線形です。

## 改造時の注意点

文字列版の文字はそのままintへ代入するため、signed char 環境の高ビット文字には注意し、必要なら非負整数列へ変換します。`lcp_array` は非空入力と正しいSAが前提です。L/Sの分類、LMSの境界比較、バケットの方向は一体なので、他実装の一部だけを移植しないでください。

## 改造後の確認

空SA/Z、1文字、全同一、周期列、長さ10/40付近の分岐を確認します。短い文字列の接尾辞直接ソートと比較し、LCP/Zは1文字ずつの比較でも確認します。
