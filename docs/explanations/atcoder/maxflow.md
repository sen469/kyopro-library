# ACL Max Flow の実装解説

[使用法に戻る](../../atcoder/maxflow.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/maxflow.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

各辺容量を超えず、途中頂点で流入と流出を等しくした最大流を求めます。既に流した分を取り消して別経路へ流せるように逆辺を置くことが重要です。例えば容量2の道と容量1の別経路があれば合計3まで流せます。

## 内部データ

`g` の `_edge` は `to,rev,cap` を持つ残余辺です。元の辺の位置を `pos` で保持し、順辺残余と逆辺残余の和が容量、逆辺残余が流量です。`level` は BFS の層、`iter` は探索済みの辺位置です。

## 処理の流れと不変条件

Dinic 法として、BFS で始点からの距離を作り、層に沿う経路で流量を増やします。この実装の DFS は終点tから始点sへ逆向きに進み、対応する順向き辺の残余容量を調べます。1層グラフで進める流れをまとめて処理してから BFS をやり直します。増加経路がなくなったとき、残余でsから到達する集合がカットになります。

## 計算量の根拠

一般グラフの上界は $O(N^2M)$、空間 $O(N+M)$。二部マッチング等ではより良い評価が可能ですが、一般容量の上界と混同しないでください。`min_cut` の到達探索は $O(N+M)$ です。

## 改造時の注意点

`change_edge` は辺単体の容量/流量を変更するだけで、全頂点の流量保存までは直しません。`flow` の再呼出しは現在の残余状態からの追加流量を返します。流量制限で途中停止した状態では `min_cut` を最小カットの証明に使えません。自己ループの逆辺番号補正も保持します。

## 改造後の確認

自己ループ、多重辺、到達不能、流量上限、追加呼出しを確認します。小Nでは全カットの容量最小値と比較し、各辺の容量制約と流量保存も検査します。
