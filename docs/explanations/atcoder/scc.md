# ACL SCC の実装解説

[使用法に戻る](../../atcoder/scc.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/scc.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

有向グラフで互いに到達できる頂点を強連結成分へ分けます。`0→1→0` と `1→2` なら `{0,1}` と `{2}` に分かれます。各成分を1頂点へ縮約すると閉路のないグラフになります。

## 内部データ

公開 `scc_graph` は内部実装へ委譲します。`internal::scc_graph` は辺を CSR にまとめ、`ord` に訪問順、`low` に未確定な探索領域へ戻れる最小の順序、`visited` にまだ成分確定していない頂点を保持します。

## 処理の流れと不変条件

Tarjan 法の DFS で子の探索結果や訪問済み頂点の順序を `low` へ反映します。`low[v]==ord[v]` ならvより前の未確定頂点へ戻れず、スタックのvまでが1成分です。確定した頂点の `ord` をNにして、以後の low 更新へ影響しないようにします。最後に成分番号を反転し、成分間の辺が前から後へ向く順にします。

## 計算量の根拠

各頂点・辺を一定回数処理するので時間・空間 $O(N+M)$。`scc()` のたびに分解を再計算し、辺追加に対する逐次更新ではありません。

## 改造時の注意点

再帰 DFS の深さは最大Nです。反復化するなら子から戻った直後の low 更新を明示的に再現します。ordのNへの変更を消す場合は、別途スタック内判定が必要になります。成分IDの順序は 2-SAT の代入決定にも使われるので変更の影響が広がります。

## 改造後の確認

自己ループ、1つの大閉路、DAG、孤立点、成分間の一方向辺を確認します。小Nで到達行列を求め、相互到達と同成分が同値か調べます。
