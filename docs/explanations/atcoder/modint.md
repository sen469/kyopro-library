# ACL Modint の実装解説

[使用法に戻る](../../atcoder/modint.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/atcoder/modint.hpp)

このリポジトリに同梱された実装を対象としています。

## 目的と基本原理

法を明示して剰余を取り続ける処理を整数型へまとめます。法7で6+3は2、3で割る操作は3の逆元5を掛ける操作です。通常の整数除算とは異なります。

## 内部データ

`_v` は常に0以上mod未満の値です。`static_modint<m>` は法が型に入り、素数性 `prime` もコンパイル時に決まります。`dynamic_modint<id>` は同じidの全オブジェクトで Barrett 還元器 `bt` を共有します。

## 処理の流れと不変条件

加減算は結果を1回補正して範囲へ戻します。静的版の乗算は64ビット積の剰余、動的版は事前計算した法の逆数近似を使う Barrett 還元です。`pow` は二分累乗。静的な素数法の `inv` は $a^{p-2}$、それ以外は拡張 Euclid で逆元を求めます。`raw` は剰余計算を省いて直接 `_v` を設定します。

## 計算量の根拠

加減乗算・比較は $O(1)$、累乗は $O(\log n)$、逆元は $O(\log mod)$。値ごとのメモリは定数です。法を静的に与えると定数剰余の最適化も利用できます。

## 改造時の注意点

`raw(v)` は必ず $0\le v<mod$ を満たす場合だけ使います。除算には分母と法が互いに素であることが必要です。動的版の `set_mod` 後、古い値をそのまま新しい法の値として使ってはいけません。異なるidは別の法を持てます。64ビット法への拡張は積の幅や Barrett 証明も含む変更です。

## 改造後の確認

負数からの構築、mod-1の加減算、指数0、合成数法の逆元、異なるdynamic idを確認します。小さい整数演算を毎回正規化した参照解と比較します。
