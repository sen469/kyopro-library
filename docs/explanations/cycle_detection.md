# Cycle Detection の実装解説

[使用法に戻る](../cycle_detection.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/cycle_detection.hpp)

## 目的と基本原理

有向・無向グラフから閉路を1つ復元します。有向の道 `0→1→2` に `2→0` があると、探索途中の祖先へ戻れるため閉路です。単に訪問済みかだけでは、探索が終了した別枝へ向かう有向辺を誤判定します。

## 内部データ

有向版の `color` は未訪問0・探索中1・終了2、`parent` は DFS 木の親です。無向版は `visited` と `parent` を使い、辺リスト版では `parent_edge` と辺 ID も保持します。

## 処理の流れと不変条件

有向版は色1への辺を見つけると親をたどり、返す列の順序を反転します。無向版では親へ戻る探索辺を除外し、既訪問頂点へ到達したら親経路の共通祖先までを接続します。自己ループは1頂点の閉路です。返り値は始点を末尾に重複させず、最後から最初への辺で閉じます。

## 計算量の根拠

DFS と高々1回の経路復元なので時間・空間とも $O(N+M)$ の範囲です。再帰 DFS の深さは最大Nで、長い道では呼び出しスタックにも注意します。

## 改造時の注意点

無向の隣接リスト版は親『頂点』への辺をすべて飛ばすため、多重辺の2辺閉路には辺 ID を持つ辺リスト版を使います。再帰をスタックへ変更する場合、有向版の探索終了タイミングを保持しないと色1/2の意味が壊れます。

## 改造後の確認

自己ループ、平行2辺、有向 DAG の合流、長い閉路、複数成分を確認します。返った頂点列の全辺と末尾から先頭の辺が実在するか検査します。
