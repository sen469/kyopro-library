# Topological Sort の実装解説

[使用法に戻る](../topological_sort.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/topological_sort.hpp)

## 目的と基本原理

有向辺 `u→v` のuがvより前になる頂点順を求めます。現在入次数0の頂点は前提条件が残っていないので先頭に置けます。`0→2,1→2` なら0と1を取り除いた後で2を取り出せます。

## 内部データ

`indegree` はまだ取り除いていない頂点からの入辺数、`que` は入次数0の頂点、`order` は確定した順です。

## 処理の流れと不変条件

最初に全辺を数え、入次数0をキューへ入れます。頂点を取り出すたびに出辺先の入次数を減らし、0になったら登録します。閉路がある部分は全頂点に前提が残るため最後まで取り出せず、`order.size()!=n` なら空配列を返します。

## 計算量の根拠

各頂点を1回、各辺を入次数計算と削除で1回ずつ扱うため $O(N+M)$。補助空間は $O(N)$、辺リスト版のグラフ構築まで含めると $O(N+M)$ です。

## 改造時の注意点

FIFO キューなので辞書順最小は保証しません。辞書順を求めるなら最小ヒープへ変え、時間も $O(M+N\log N)$ になります。空グラフ成功と閉路による失敗はどちらも空配列なので、Nも見て区別します。

## 改造後の確認

自己ループ、非連結 DAG、閉路と孤立点の混在、多重辺を確認します。成功時は各辺で順序を満たすか、失敗時は全頂点が取り出せないか確認します。
