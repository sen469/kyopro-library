# Persistent Segtree の実装解説

[使用法に戻る](../persistent_segtree.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/persistent_segtree.hpp)

## 目的と基本原理

点更新の各版を残すセグメント木です。配列 `[1,2,3]` の中央を9にした新版の総和は13、旧版の総和は6のままです。全体を複製せず、更新する葉の祖先だけを複製します。

## 内部データ

`root_` が版ごとの根、`nodes_` は `shared_ptr` で共有するノードプールです。各ノードに `prod,left,right` を保持します。番号0の区間は未生成で単位元、`n_` が実際の配列長です。

## 処理の流れと不変条件

`set` は子番号を値として取り出し、片方だけを再帰更新した後、新しい親を作ります。旧ノードの内容には代入しません。クエリは版の根から区間を分割し、左右の順で結合します。`max_right/min_left` は累積値 `sm` を探索方向に合わせて結合します。

## 計算量の根拠

点更新・区間集約・境界探索は $O(\log N)$。配列からの構築は $O(N)$、サイズのみの構築は $O(1)$。更新ごとに $O(\log N)$ ノードを追加し、版オブジェクトのコピーは共有ポインタと根番号のコピーです。

## 改造時の注意点

共有プールに追加しても、既存ノードを書き換えてはいけません。`node_count` は全版で共有するプールの値です。遅延伝播を加えるなら `push` で触る子もコピー対象となります。集約関数の結合則と単位元、境界探索の単調性も保持します。

## 改造後の確認

祖先版からの分岐、同一点を繰り返し更新、空配列と空区間、非可換演算を確認します。各版を通常の配列として保存する愚直解と比較します。
