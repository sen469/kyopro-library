# Wavelet Matrix の実装解説

[使用法に戻る](../wavelet_matrix.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/wavelet_matrix.hpp)

## 目的と基本原理

静的配列の区間内順位や出現数を扱います。毎回区間をソートする代わりに、値を上位ビットから安定に0群と1群へ分けた各段を保存します。`[3,1,2]` を圧縮して `[2,0,1]` とすると、最上位段は0群 `[0,1]`、1群 `[2]` に分かれます。

## 内部データ

`values` は重複を除いたソート値、`matrix` は各段の `bit_vector`、`mid` は0群の長さです。この bit_vector はビット圧縮構造ではなく、int の累積和 `sum` で `rank0/rank1` を返します。

## 処理の流れと不変条件

安定分割なので元の区間に属する0群/1群は次段でも連続区間になります。0群への写像は `[rank0(l),rank0(r))`、1群はさらに `mid` を足します。`kth_smallest` は0群の数より順位が大きければ1群へ進み、順位を減算します。`count_less` は上限のビットが1の段で0群を答えに加えます。

## 計算量の根拠

異なる値数を $\sigma$ とすると構築はソートを含め $O(N\log N+N\log(\sigma+1))$、問い合わせは $O(\log(\sigma+1))$。空間は $O(N\log(\sigma+1))$ 個の整数で、コンパクトなビット列実装より大きくなります。

## 改造時の注意点

値を更新すると安定分割の順序が変わるため点更新を単純追加できません。値域集約を足すなら各段の並べ替えと同じ順序で補助配列を構築します。前後値が存在しない場合は assert の対象です。`\sigma=1` では段数0でも値を復元できます。

## 改造後の確認

全値同一、負数、未登録の上限、空区間の頻度、順位0と末尾を確認します。部分配列のソートと直接カウントを参照解にします。
