# Segtree の実装解説

[使用法に戻る](../segtree.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/segtree.hpp)

## 内部データと構築

論理的な列長 `n_` と、`n_` 以上の最小の 2 冪 `base_` を保持します。
配列 `data_` の `[base_, base_+n_)` が実際の葉で、残りの葉には単位元を置きます。
親は左の子と右の子の積を持ち、根 `data_[1]` が全体の積です。
空の列でも `base_=1` として根を確保し、`all_prod()` が単位元を返せるようにします。

配列からの構築は葉をコピーして、末尾側の内部ノードから根へ順に計算します。
長さだけ指定した場合は木全体を単位元で初期化します。
ACL の継承や呼び出しを使わない、独立した実装です。

## 点更新と区間積

点更新は葉を置き換えて祖先だけを再計算するので $O(\log(n+1))$ です。
区間積は左右の端を葉から根へ上げ、区間内に収まる部分木を集めます。
左側の集約には右へ追加し、右側の集約には左へ追加することで、
非可換な演算でも元の添字順を維持します。

## 境界探索

`max_right` は開始位置より左の部分木を飛ばし、左から右へ部分木を走査します。
部分木を現在の集約の右に加えても述語が真なら、その部分木を丸ごと採用します。
偽になる部分木だけを子へ分解し、最初に条件を満たさなくなる葉の位置を返します。

`min_left` は右から左へ同様に探索します。積の順序を保つため、部分木の積を
現在の集約の左に加えます。最初に条件を満たさなくなる葉の右端が答えです。
これらの探索は単調な述語の下で、開始位置までの経路と失敗位置までの経路、および
その兄弟部分木だけを調べるため $O(\log(n+1))$ です。
区間積を呼びながら外側で二分探索する $O(\log^2 n)$ の構成ではありません。

## size と to_vec

`size()` は列の長さ `n_` をそのまま返します。
`to_vec()` は実際の葉の区間だけをコピーするので $O(n)$ です。
各点を探索し直す必要はなく、内部の埋め草も返しません。
遅延伝播を持たないので読み取り専用の `const` 関数として実装できます。

## 改造時の注意と確認

演算に必要なのは結合律と単位元で、可換性は不要です。
特に `prod` の右側の集約と `min_left` の順序を逆にしないようにします。
空の列・空区間・2 冪でない列長では、単位元の埋め草と端点の扱いを確認します。

テストは通常の配列による区間積・線形境界探索と ACL の結果を参照します。
文字列連結で非可換な演算を確認し、関数ポインタ・ラムダの両形式、
`const` からの取得、コピーの独立性、`to_vec()` の返り値の独立性も検証します。
