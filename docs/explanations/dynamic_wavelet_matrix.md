# Dynamic Wavelet Matrix の実装解説

[使用法に戻る](../dynamic_wavelet_matrix.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/dynamic_wavelet_matrix.hpp)

## 基本原理

Wavelet Matrix の各ビット段を動的ビット列に置き換えます。
各段は、現在の列をその段のビットで 0 群・1 群に安定分割した順序を表します。
`zeros_[depth]` は 1 群の開始位置です。
符号付き整数の符号ビットを反転し、通常の整数順序で Kth を求めます。

## 動的ビット列

各段は AVL 木の葉に最大 64 ビットを詰めて保持します。
内部ノードは左右の子、部分木のビット数、1 の個数、高さを持ちます。
位置アクセスや `rank1(r)` は部分木のビット数を使って下り、
接頭辞に含まれる 1 の数を足し合わせます。

葉に空きがあればビット演算で挿入します。満杯の葉に挿入すると 65 ビットになるため、
32 ビットと 33 ビットの葉へ分割します。削除時は空の葉を外し、
兄弟の葉が合計 64 ビット以下なら結合します。木の高さは AVL 回転で維持します。
不要ノードは再利用リストへ戻します。

## 挿入・削除と位置の写像

段内の位置 `i` より前の 1 の数を `ones` とすると、次の段の位置は
ビット 0 なら `i - ones`、ビット 1 なら `zeros_[depth] + ones` です。
挿入時は現在の段での挿入位置を次段へ写像していき、0 を追加した段では
`zeros_` を増やします。

削除時は、削除前のビットと `zeros_` を使って次段の位置を決め、
現在の段から削除します。0 を削除した段では `zeros_` を減らします。
`set` は同じ位置から削除した後、その位置に新値を挿入します。

## 区間クエリ

各段で区間 `[l, r)` に含まれる 0 の数を `rank1(l)` と `rank1(r)` から求めます。
Kth は順位が 0 群に収まれば 0 群へ、そうでなければ 0 群の数を順位から引いて
1 群へ進みます。頻度や値の個数も同じ区間写像を使います。
この部分は静的 Wavelet Matrix と同じ原理です。

## 計算量と注意点

AVL 木の操作は $O(\log(n+2))$、段数は値型のビット数 `B` なので、
挿入・削除・点更新・位置アクセス・区間クエリは $O(B\log(n+2))$ です。
初期構築は各段の安定分割と平衡木の一括構築で $O(B(n+1))$ です。
ノード配列・再利用リストは `vector` なので、領域拡張を含む更新時間は償却計算量です。

葉の占有率は更新により変わるため、空間の厳密な最悪上界は
$O(B(n+1))$ ワードです。ビット列本体は各段 `n` ビットですが、
AVL 木の管理情報を含めた実装全体が `nB` ビットに収まるわけではありません。
確保済みノード領域は過去の最大ノード数に依存します。

葉の長さが 64 のときのマスクや末尾削除では、64 ビットシフトを実行しないよう
分岐します。挿入時にはノード配列が再確保されるので、再帰呼び出しをまたいで
ノードへの参照を保持しません。

## 確認方法

動的ビット列は通常の配列と比較し、長さ 63・64・65 前後の分割と結合を確認します。
Wavelet Matrix は列の挿入・削除・更新を混ぜたランダムテストで、各部分列をソートした
全順位と直接カウントを参照解にします。負数、重複、整数型の端点、空列からの追加、
全削除後の再追加、コピーの独立性、再構築を確認します。
