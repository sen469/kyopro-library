# Euler Tour の実装解説

[使用法に戻る](../euler_tour.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/euler_tour.hpp)

## 目的と基本原理

木の部分木を一次元配列の区間へ変換します。DFS で頂点を初めて訪問した順に並べると、ある頂点の子孫は、その頂点の探索が終わるまで連続して訪問されます。0の子が1と2、1の子が3なら順序 `[0,1,3,2]` で1の部分木は `[1,3)` です。

## 内部データ

`order_` は各頂点を1回並べる列、`in_` は入ったときの位置、`out_` は探索終了時の列長です。`parent_`,`parent_edge_`,`depth_`,`component_` は DFS 森の情報、`built_` は構築済みかを表します。

## 処理の流れと不変条件

`dfs` は `(頂点,次に見る隣接辺番号)` の明示スタックで再帰の入口/出口を再現します。訪問時に `in_` と `order_` を設定し、全辺を見終わったら `out_` を設定します。指定した根を先に処理してから残る成分も走査します。祖先判定は同じ成分で区間が包含されるかで決まります。

## 計算量の根拠

構築は $O(N+M)$、各情報取得は $O(1)$、空間 $O(N+M)$。深い木でも C++ の再帰スタックを消費しません。

## 改造時の注意点

これは往復で頂点を記録する長さ $2N-1$ の列ではなく、初訪問順の長さNの列です。LCA の RMQ 用列とは異なります。閉路入力では訪問済み辺を飛ばして DFS 森を作るので、元グラフの任意の到達集合とは一致しません。辺追加後は再 build が必要です。

## 改造後の確認

1頂点、複数成分、指定根順序、根の変更、各部分木サイズ `out-in` を確認します。親をたどる祖先判定と区間包含を比較します。
