# Dynamic Segtree の実装解説

[使用法に戻る](../dynamic_segtree.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/dynamic_segtree.hpp)

## 目的と基本原理

巨大な整数座標の範囲に対して、使う部分だけを確保するセグメント木です。例えば範囲 $[0,10^{12})$ の1点を更新すると、全座標を確保せずその点までの二分経路だけを生成します。

## 内部データ

`left_bound_`,`right_bound_` は管理する半開区間です。`root` と各 `node` の `left,right` が二分木を作り、`prod` が区間全体の集約値です。未生成ノードの値は `e()` とみなします。

## 処理の流れと不変条件

`set` は対象を含む子だけをたどり、帰りがけに `op(left,right)` を計算します。`prod` は区間外なら単位元、完全に含まれるなら保存値を返します。例えば文字列連結のように順序が重要でも、左から右の合成順を維持します。境界探索は区間を丸ごと追加できる間は進み、条件が破れる部分だけ下降します。

## 計算量の根拠

座標幅を $U$、更新回数を $Q$ とすると通常の操作は $O(\log U)$、ノード数は $O(Q\log U)$ 以下です。コピーは `clone` による深いコピーなので確保ノード数に比例します。破棄も全ノードを巡回します。

## 改造時の注意点

`e()` は未更新区間全体の意味でもあります。区間長を持つ集約などでは未生成値の扱いを再設計してください。`r-l` が `long long` に収まる必要があります。境界探索の述語は `f(e())=true` と単調性が必要です。遅延更新を追加する場合はタグだけでなく未生成の子への作用も設計します。

## 改造後の確認

負座標、幅1、空区間、未更新の取得、同一点再更新、コピー後の独立性を確認します。小さい範囲の配列と非可換な集約でも比較します。
