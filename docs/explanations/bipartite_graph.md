# Bipartite Graph の実装解説

[使用法に戻る](../bipartite_graph.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/bipartite_graph.hpp)

## 目的と基本原理

無向グラフの全辺の両端を異なる2色に塗れるか判定します。道 `0-1-2` は `0,1,0` と塗れますが、さらに `2-0` を加えると同色同士が隣接して不可能です。

## 内部データ

`graph_` が隣接リスト、`colors_` は未訪問の-1または色0/1です。`checked_` は判定キャッシュの有効性、`bipartite_` は結果です。問い合わせは const ですが、mutable な結果配列を構築します。

## 処理の流れと不変条件

`build` は未訪問の各成分から BFS し、隣接頂点へ `colors_[v]^1` を割り当てます。既に同じ色なら矛盾です。木の辺で色が決まった後、残りの全辺も確認するため、奇閉路が存在すると失敗します。`add_edge` はキャッシュを無効化します。

## 計算量の根拠

1回の再判定は $O(N+M)$、空間 $O(N+M)$。辺変更がなければ判定結果の再利用は $O(1)$ です。辺を1本追加するたびに判定すると、そのたびに全探索します。

## 改造時の注意点

隣接リストコンストラクタには無向グラフを渡します。色の配列は判定成功時だけ取得できます。オンライン追加ごとに高速判定したいなら parity 付き Union Find など別方式が必要です。頂点重みなどを追加しても判定キャッシュの無効化条件を明確にします。

## 改造後の確認

偶閉路、奇閉路、自己ループ、孤立点、非連結グラフ、成功判定後の辺追加を確認します。小さいNなら全 $2^N$ 通りの彩色で比較できます。
