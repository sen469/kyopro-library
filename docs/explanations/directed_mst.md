# Directed MST の実装解説

[使用法に戻る](../directed_mst.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/directed_mst.hpp)

## 目的と基本原理

指定した根から全頂点へ届く、重みの合計が最小の有向木を求めます。
根以外の頂点には入辺がちょうど1本必要です。
各頂点で最小重みの入辺を選び、閉路がなければそれが最適解になります。
ただし有向閉路ができると根につながらないので、その閉路を1頂点へ縮約して解き直します。

例えば辺が `0->1:5, 0->2:6, 1->2:1, 2->1:1` の場合、
最小の入辺だけを選ぶと1と2の間に閉路ができます。
閉路への入辺を比較して、`0->1` と `1->2` の合計6を選びます。
無向版のDSUによる閉路除去だけでは、根からの到達性と各頂点の入次数を同時に扱えません。

## 内部データ

`edges_` は変更しない元の辺リストです。
`work_edge` は現在の縮約グラフの端点・補正後の重み、
元の辺ID `original`、直前の段階の辺添字 `previous` を持ちます。
`incoming[v]` は現在の頂点vに対して選んだ最小入辺の添字で、根だけは-1です。
`history` は各縮約段階の辺リストと `incoming` を保存します。

## 到達判定と入辺選択

最初に根から有向辺をたどって全頂点に到達できるか判定します。
到達不能な頂点があれば全域有向木は存在しません。
到達可能なら探索木自体が全域有向木になるため、存在は保証されます。
自己ループと根への入辺は作業用グラフから除きます。
以降、根は閉路に含まれず、縮約後も根への入辺がない状態を維持します。

各頂点の最小入辺を走査で選びます。
重みが同じ場合は先に現れた辺を維持します。
縮約後も元の辺順を保って列挙するため、同じ補正重みなら元のIDが小さい辺が選ばれます。
無限大の重みを番兵として使わず、入辺添字-1で未選択を表します。

## 閉路の縮約

選んだ入辺を親方向へたどると、根に到達するか閉路に入ります。
`visited` に探索開始頂点を記録し、今回の探索で訪問した頂点に戻れば閉路です。
以前の探索で訪問済みならそこで終了するので、1段階で各頂点を高々1回たどります。
すべての閉路をそれぞれ1頂点にし、それ以外は単独の頂点として残します。

辺 `u->v` が異なる縮約成分を結ぶ場合、重みを
`cost(u,v) - cost(incoming[v])` に置き換えます。
各頂点の最小入辺の合計を基準とし、その入辺を別の辺に置き換える追加費用を表しています。
閉路に外から入る辺を1本選ぶと、その行き先の既存入辺を外せば閉路が切れます。
最小入辺で作った閉路では、この交換で縮約グラフの最適解を元の最適解へ対応させられます。
閉路でない単独頂点への辺にも同じ補正を行い、基準の入辺を置き換える費用として統一します。
縮約成分内の辺は次の段階では不要です。

閉路がなくなるまで繰り返します。
1回の縮約で頂点数が必ず減るので、段階数は高々O(n)です。

## 採用辺の復元

最後の段階の `incoming` が縮約後の木です。
1段階戻るときは、その段階で最初に選んだ入辺集合をいったん復元します。
縮約後に採用した各辺の `previous` をたどり、
元の行き先頂点の入辺をその辺で上書きします。
これにより閉路への入口の入辺だけが置き換わり、残りの閉路辺は有向木の一部として残ります。
単独頂点の入辺も同じ上書きで正しく復元されます。
入れ子の縮約にも、段階を逆順に戻ることで対応できます。

最終的な採用辺を元のIDへ戻して昇順にし、元の重みを足してコストを求めます。
同時に、親配列を全要素-1で初期化して、採用辺 `u->v` ごとに `parents[v] = u` を設定します。
根への入辺は採用しないので根の親は-1のままです。`parent(v)` はこの配列を参照します。
親配列の生成は時間・空間ともに $O(n)$ で、全体の計算量の上界は変わりません。
失敗時には部分的な辺集合を返しません。

## 計算量の根拠

各段階の頂点数・辺数をn_i,m_iとすると、縮約と復元は合計 $O(\sum_i(n_i+m_i))$、
最後の辺IDのソートは $O(n\log(n+1))$ です。
最初の到達判定は $O(n+m)$ です。
全履歴を保存するため、追加空間は $O(n+m+\sum_i(n_i+m_i))$ です。
段階数はO(n)、頂点数・辺数は増えないので、保守的な上界は時間・空間ともに $O(n(n+m))$ です。
非自明な到達可能グラフでは $m\ge n-1$ なので $O(nm)$ と表せます。
大規模な入力向けの高速版ではない点に注意してください。

## 改造時の注意点

縮約時の重みは元の重みではなく、現在の補正後の重みから差し引きます。
元の辺IDだけでなく直前の段階の辺添字を保持しないと、入れ子の閉路の復元が難しくなります。
根の入辺を選んだり、自己ループを候補に残したりしないでください。
全辺を反転すれば根へ集まる有向木に応用できますが、返るIDと元の向きの対応は呼び出し側で管理します。
符号付き整数の減算と合計の中間オーバーフローに注意してください。
浮動小数点では補正の繰り返しによる誤差があります。

## 改造後の確認

小さいグラフでn-1本の全辺部分集合を列挙し、
根の入次数0・他の入次数1・根からの全頂点到達を満たすものの最小コストと比較します。
復元した辺でも同じ条件とコストを検査します。
親配列が採用辺と一致し、根の親が-1で、全頂点から親をたどると根に着くことも確認します。
単一閉路、複数閉路、入れ子の縮約、到達不能な閉路、負の重み、自己ループ、多重辺、根への入辺を確認します。
根変更・辺追加後の再計算、同重みでの再現性、空・1頂点、長い道も
`test/directed_mst_test.cpp` に用意しています。
