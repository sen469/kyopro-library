# Lowest Common Ancestor の実装解説

[使用法に戻る](../lowest_common_ancestor.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/lowest_common_ancestor.hpp)

## 目的と基本原理

根付き木の2頂点に共通する最も深い祖先を求めます。親を1段ずつ登ると長い道で遅いため、$2^k$ 段上の祖先を前計算します。0の子1、1の子2と3なら `lca(2,3)=1` です。

## 内部データ

`parent_[k][v]` は $2^k$ 段上の祖先で、存在しないと-1です。`depth_` は根からの辺数、`component_` は木の番号、`built_` は構築状態です。

## 処理の流れと不変条件

反復 DFS で親と深さを決め、`parent_[k+1][v]=parent_[k][parent_[k][v]]` を構築します。クエリは深さを合わせ、既に同頂点ならそれが答えです。違えば大きな段数から「飛んだ先も異なる」間だけ両者を上げ、最後の親を返します。共通祖先を飛び越えない条件で最深位置まで近づく方法です。

## 計算量の根拠

前処理と空間は $O(N\log N+M)$、LCA・k段祖先は $O(\log N)$。距離は `depth[u]+depth[v]-2*depth[lca]` により同じ計算量です。

## 改造時の注意点

木/森の構築後に問い合わせます。`dist` は辺数であり重み付き距離ではありません。重み付き化は根からの重み和を別保存します。現在 `build()` は空グラフでも既定根0へアクセスするため、空なら呼ばず、必要なら `build(std::vector<int>{})` とします。コードの修正は本解説の対象外です。

## 改造後の確認

祖先同士、同一頂点、異なる成分、根より上への移動、長い道を確認します。親を1段ずつたどる愚直 LCA と比較し、辺追加後の再構築も確認します。
