# Weighted Union Find の実装解説

[使用法に戻る](../weighted_union_find.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/weighted_union_find.hpp)

## 目的と基本原理

連結性に加えて頂点のポテンシャル差を管理します。制約 $P(b)-P(a)=w$ を辺として追加し、既存の制約と矛盾しないか判定できます。例えば $P(1)-P(0)=3$、$P(2)-P(1)=4$ なら $P(2)-P(0)=7$ です。

## 内部データ

`parent_or_size` は通常の Union Find と同じです。`diff_weight[v]` は現在の親との差 $P(v)-P(parent(v))$。根では0です。`potential(v)` は経路圧縮後の根との差を返します。

## 処理の流れと不変条件

`leader` は先に親を根へ圧縮してから親の重みを加え、頂点から根までの差を保存します。根を `x,y`、元の頂点の根との差を `wa,wb` とすると、`y` を `x` の下へ付ける重みは `w+wa-wb`。サイズ比較で根を交換したらこの差も反転します。同根なら `wb-wa==w` を判定するため、`merge` の真偽は新規併合の有無ではなく整合性です。

## 計算量の根拠

加減算と比較が定数時間なら操作はならし $O(\alpha(N))$、メモリ $O(N)$。重みの大きな型を使う場合はその演算費用を掛けます。

## 改造時の注意点

差の向きを変更すると `merge`、`diff`、経路圧縮を一緒に変更する必要があります。異なる成分間の差は未定義です。不整合を一度見つけても恒久的なフラグは保存しないので、その後も「矛盾した成分」を追いたい場合は根に状態を追加します。

## 改造後の確認

正負の差、根の交換、閉路が整合する例と矛盾する例、圧縮前後の差を確認します。小さな制約グラフで根から直接加算したポテンシャルと比較します。
