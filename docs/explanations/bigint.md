# Bigint の実装解説

[使用法に戻る](../bigint.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/bigint.hpp)

## 目的と基本原理

組込み整数より大きい整数を桁配列で表します。十進数を1桁ずつではなく9桁ずつまとめ、$10^9$ 進数の筆算を行います。例えば1000000001は下位から `[1,1]`、負数は同じ桁配列と負の符号で表します。

## 内部データ

`sign_` は-1/0/1、`digits_` は下位桁からの非負配列です。`trim` は上位の0を除き、0を空配列・符号0へ統一します。`base` は $10^9$、大きい乗算時だけ `fft_base=1000` へ分解します。

## 処理の流れと不変条件

加減算は符号を分けて絶対値の加算/減算へ帰着し、繰上げ・借りを伝播します。小さい乗算は筆算、大きい乗算は3桁単位へ分けて ACL の整数畳み込みを行い、繰上げを処理して9桁単位へ戻します。`multiply_abs_fft` という名前でも浮動小数点 FFT ではありません。

除算の通常経路は上位桁を正規化して商の1桁を推定し、大きすぎれば補正します。大きい入力では `decimal_inv` が逆数を `d+d*(1-b*d)` で改善し、商を丸めて余りから補正する経路です。最後に商は0方向への丸め、余りは被除数と同符号へ戻します。例えば $-7/3=-2$、余りは-1です。

## 計算量の根拠

桁数N,Mについて加減算は $O(N+M)$、筆算乗算 $O(NM)$、畳み込み乗算は $O((N+M)\log(N+M))$。通常除算は概ね $O((N-M+1)M)$、1桁除算は線形です。高速除算は多倍長乗算・精度を変える反復に依存し、すべての除算を一定時間や単純な線形時間とは見積もれません。保存空間は桁数に比例します。

## 改造時の注意点

baseを変えるなら入出力桁数・乗算上界・正規化・畳み込みへの分割をすべて揃えます。高速除算の商補正は誤差の上界に依存するため精度定数を安易に減らしません。`to_integral` は範囲検査がなく、正の絶対値を蓄積するので、符号付き最小値への変換も中間値に注意します。

## 改造後の確認

符号の全組合せ、0、先頭0、繰上げ/借りの連鎖、自己演算、除数1を確認します。除算は `a=q*b+r` と余りの範囲・符号を検査し、乗算閾値80桁と除算閾値120桁の前後も比較します。
