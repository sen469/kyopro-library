# Interval Set の実装解説

[使用法に戻る](../interval_set.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/interval_set.hpp)

## 目的と基本原理

整数集合を1個ずつ保持する代わりに、連続部分を半開区間にまとめます。`[1,4)` と `[4,7)` を追加すると `[1,7)` になり、そこから `[3,5)` を削除すると `[1,3),[5,7)` です。

## 内部データ

`intervals_` は左端から右端への map です。不変条件は、各区間が空でなく、互いに重ならず、隣接もしていないこと。`size` は整数の個数ではなく区間数です。

## 処理の流れと不変条件

`add` は左端直前の区間を確認してから、右へ重なる/隣接する区間を吸収します。`erase` は交差区間を取り除き、削除範囲の左右に残る端を再挿入します。`find` は `upper_bound(x)` の直前だけを調べれば十分です。隣接区間がないため、含まれる区間の右端がそのまま `mex(x)` になります。

## 計算量の根拠

区間数を $K$、触る区間数を $k$ とすると、検索は $O(\log(K+1))$、追加削除は $O(\log(K+1)+k)$。削除のイテレータ操作はならし定数時間で、残る端は高々2つです。空間は $O(K)$。

## 改造時の注意点

閉区間へ変更するなら比較と mex の意味を全面的に見直します。`right+1` の変換は最大整数であふれます。整数総数を返したい場合は区間長の和を別管理し、区間の統合・分割の両方で差分更新します。

## 改造後の確認

空区間、包含追加、隣接統合、中央だけの削除、存在しない部分の削除、負数の mex を確認します。小さい座標の bool 配列と比較できます。
