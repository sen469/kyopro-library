# KMP の実装解説

[使用法に戻る](../kmp.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/kmp.hpp)

## 目的と基本原理

テキストからパターンを探す際、失敗のたびに最初から比較し直す無駄を避けます。`ababa` の途中まで一致して失敗したら、既に一致した部分の接尾辞 `aba` などを次の接頭辞候補として使えます。

## 内部データ

`prefix[i]` はパターンの先頭からiまでにおける、全体を除いた最長の接頭辞かつ接尾辞の長さです。検索中の `j` は今一致しているパターン先頭の長さです。

## 処理の流れと不変条件

`prefix_function` と検索の両方で、不一致時に `j=prefix[j-1]` と短い候補へ戻します。この候補だけを試せば、既に一致した文字列と両立する全候補を調べられます。一致を発見した後も同じ戻り先を使うため重なり一致を検出します。`aaa` 中の `aa` は開始0と1の両方が見つかります。

## 計算量の根拠

テキスト長N・パターン長Mで前計算 $O(M)$、検索 $O(N+M)$。jの増加は各文字で高々1、減少の総量も増加量以下なので while があっても線形です。補助配列 $O(M)$ に加え、全一致を返す場合は出力数のメモリが必要です。

## 改造時の注意点

空パターンの検索は全境界0～N、最初の一致は0です。ストリーミング化は `prefix` とj、読んだ文字数を保存すれば可能ですが、チャンクごとにjを0へ戻さないでください。単純な等値比較を前提としているため、ワイルドカード導入は接頭辞構築から検討します。

## 改造後の確認

重なる一致、不一致の連続、パターンが長い場合、空、整数列での検索を確認します。全開始位置を直接比較する方法と照合します。
