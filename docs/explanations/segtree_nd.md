# Segtree ND の実装解説

[使用法に戻る](../segtree_nd.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/segtree_nd.hpp)

## 目的と基本原理

多次元配列の点更新と直方体の集約を扱います。2次元なら各軸でセグメント木の区間を選び、その直積の長方形を結合します。例えば行 `[1,3)`・列 `[2,5)` を、それぞれの軸の少数の区間へ分解します。

## 内部データ

`sizes_` は元の長さ、`seg_sizes_` は各軸を2のべき乗へ切り上げた葉数、`strides_` はノード座標を `data_` に平坦化する係数です。座標が全軸1のノードが全体の集約です。

## 処理の流れと不変条件

`build_axis` は軸ごとに子2つをまとめます。`set` は全軸の祖先経路 `paths` を作り、葉からの距離の総和が小さい順に祖先の直積を更新します。子が先に更新済みとなる順序です。`prod_nodes` は各軸の区間ノードを集め、`prod_dfs` が直積を巡回します。

## 計算量の根拠

確保量は $P=\prod_i(2s_i)$（$s_i$ は切上げ葉数）。構築は添字計算のDも数えると $O(D^2P)$ の上界です。クエリは $O(D\prod_i(1+\log n_i))$。更新対象は祖先の直積ですが、現在の実装は距離総和ごとに DFS を繰り返すため列挙の追加費用があり、同じ積だけを無条件に実行時間とみなさないでください。

## 改造時の注意点

多次元の分割方向や `prod_nodes` の列挙順が一意な一次元順序にならないため、可換モノイドを使います。非可換演算は1次元の場合も現在の列挙方法では保証しません。高次元での積のメモリ超過や添字乗算のオーバーフローに注意し、疎な用途なら構造自体を変えます。

## 改造後の確認

1次元、各軸長1、空軸、端の1点、長さが2のべき乗でない配列を確認します。点更新後に全直方体を愚直集約と比較します。
