# Arbitrary Mod Convolution の実装解説

[使用法に戻る](../arbitrary_mod_convolution.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/arbitrary_mod_convolution.hpp)

## 目的と基本原理

任意の正のint法で多項式積を求めます。係数列 `[1,2]` と `[3,4]` の積は `[3,10,8]` で、法7なら `[3,3,1]`。目的の法で NTT ができない場合も、NTT 向きの3素数で計算して結果を復元できます。

## 内部データ

`MOD1,MOD2,MOD3` は固定の異なる素数、`x,y` は入力を目的法の非負剰余に直した配列、`c1,c2,c3` は各素数の畳み込みです。事前計算した逆元を復元で共有します。

## 処理の流れと不変条件

各係数を $r_1+MOD1\,t_1+MOD1\,MOD2\,t_2$ と表します。2番目の剰余に合わせてt1、3番目に合わせてt2を決め、最後に目的法で剰余を取ります。3法の積未満の非負係数なら、この復元は一意です。負の入力も先に目的法で正規化するため同じ答えになります。

## 計算量の根拠

出力長Lに対して3回の ACL 畳み込みと復元なので $O(L\log L)$、空間 $O(L)$。各素数の対応長から $L\le2^{24}$ が必要です。この長さとint法の範囲では正規化後係数の上界 $\min(N,M)(mod-1)^2$ が3法の積より小さくなります。

## 改造時の注意点

法の型や最大長を拡張する場合、NTT の根の次数だけでなく CRT の復元可能範囲を再確認します。積の中間値は `__int128` を使います。3法のどれかを変えるなら逆元と長さ制限も変更します。

## 改造後の確認

空入力、法1、負係数、1要素、大きい法を愚直な畳み込みと比較します。素朴法/NTT の分岐をまたぐ長さも確認します。
