# Doubling の実装解説

[使用法に戻る](../doubling.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/doubling.hpp)

## 目的と基本原理

同じ遷移を大量に繰り返した後の位置を求めます。13回なら8回・4回・1回に分け、前計算したジャンプを3回使います。木に限らず、循環する遷移や終端のある状態にも使えます。

## 内部データ

`next_[k][v]` は $2^k$ 回後の状態、`max_step_` は許される回数、`log_` は必要な段数です。`doubling_monoid` は同じ区間で通る値を `value_[k][v]` に保持します。終端は-1です。

## 処理の流れと不変条件

`build` は半分のジャンプを2回つないで次段を作ります。集約版も前半・後半の順に `op` で結合します。`jump` は回数の立っているビットごとに現在位置から飛び、値を答えの末尾へ加えます。終端で停止し、存在する遷移の分だけ集約します。`set_next(v,-1,value)` の value は単位元に置き換えられます。

## 計算量の根拠

最大回数をKとして前処理・空間 $O(N\log(K+1))$、問い合わせ $O(\log(K+1))$。各集約操作を定数時間とした評価です。

## 改造時の注意点

遷移変更後は `build` が必要です。Kを超える問い合わせや負の回数は許しません。文字列連結等の非可換演算では前半と後半の順を維持します。終端への最後の移動に値を含めたい場合は、今の-1の意味から再設計します。

## 改造後の確認

0回、最大回数、自己ループ、複数周期、途中終端を確認します。小さい回数の逐次移動と比較し、集約版は移動順が分かる値でも確認します。
