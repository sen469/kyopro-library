# Geometry の実装解説

[使用法に戻る](../geometry.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/geometry.hpp)

## 目的と基本原理

点・直線・線分・円の関係を内積、外積、距離で判定します。内積は射影方向、外積は向きと平行性を表します。例えばx軸と点 `(0,2)` の距離は、方向ベクトルとの外積の絶対値を方向の長さで割って2になります。

## 内部データ

`point` は long double のx,y、`line` は通る2点、`circle` は中心と半径です。`sign/equal/lt/le/gt/ge` が `default_eps` を用いて比較結果を揃えます。

## 処理の流れと不変条件

直線上判定は外積0、線分上判定はそれに端点からの内積条件を追加します。線分との距離は射影が端の外なら端点距離、内側なら直線距離です。線分交差では同一直線上を別扱いし、座標区間の重なりを見ます。円同士は中心距離dと半径和・差を比較し、分離・接触・交差・包含・一致を分類します。

## 計算量の根拠

各操作は一定個数の四則演算や平方根なので $O(1)$、追加空間も $O(1)$。多数の図形を探す索引や凸包はこのヘッダの役割ではありません。

## 改造時の注意点

eps は絶対誤差の基準です。座標スケールを変えると外積や積の誤差の尺度も変わるため一律のeps変更だけで解決するとは限りません。直線の2点は異なる必要があります。`segment_circle_relation` は線分と中心の最短距離による0/1/2分類で、円周との交点数ではありません。円内部に全線分がある場合も2となります。

## 改造後の確認

平行・同一直線・端点接触・ゼロ長線分・内接外接・一致円と、epsの前後を確認します。座標を拡大縮小したときの結果も調べます。
