# Manacher の実装解説

[使用法に戻る](../manacher.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/manacher.hpp)

## 目的と基本原理

全中心の回文半径を線形時間で求めます。各中心から個別に広げると `aaaa...` で二乗になりますが、既知の回文区間の対称位置にある半径を再利用できます。`ababa` の中央の奇数半径は3、`abba` の中央の偶数半径は2です。

## 内部データ

`odd[i]` は中心自身を含む半径、`even[i]` はiの直前を中心とする左右の長さです。`left,right` はこれまでで右端が最も先にある回文の閉区間です。

## 処理の流れと不変条件

中心iが既知区間内なら鏡像の半径と右端までの距離の小さい方を初期値にします。区間外へ出る部分だけ新しく比較し、より右まで伸びたら `left,right` を更新します。既知回文の内部は対称性で保証でき、右端の外側だけは未確認なので比較が必要です。`is_palindrome(l,r)` は区間の奇偶に応じて中心と必要半径を計算します。

## 計算量の根拠

右端が前進する回数は高々Nで、各中心の最後の失敗比較も高々1回なので全体 $O(N)$。空間 $O(N)$、構築済みの回文判定は $O(1)$ です。

## 改造時の注意点

奇数半径と偶数半径の意味を統一してしまうと1ずれが生じます。文字列更新への追従はできないので再構築が必要です。比較対象は文字に限らず、等値比較できる配列にも使えます。

## 改造後の確認

空、1文字、偶数回文、全同一、回文でない全区間を確認します。全 `[l,r)` を直接反転比較し、返り値と照合します。
