# Interval Heap の実装解説

[使用法に戻る](../interval_heap.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/interval_heap.hpp)

## 目的と基本原理

最小値と最大値を両方取り出せる多重集合です。名前は interval heap ですが、この実装は区間を持つ配列ヒープではなく `std::multiset` の薄いラッパーです。`[1,3,3]` から最大を1個削除すると `[1,3]` になります。

## 内部データ

唯一の保存先 `data_` が Compare に従って要素を整列します。重複要素は別要素として保存されます。`min/max` はそれぞれ先頭/末尾への参照を返します。

## 処理の流れと不変条件

`push/emplace` は集合へ挿入します。`pop_min` は `begin()`、`pop_max` は `--end()` のイテレータを削除するため、重複を1個だけ消します。平衡性や順序維持は標準ライブラリが担当します。

## 計算量の根拠

挿入は $O(\log N)$、両端参照は $O(1)$。イテレータ指定の削除は標準 multiset のならし定数時間で、対数時間の上界でも説明できます。初期構築は逐次挿入なので $O(N\log N)$、空間は $O(N)$。

## 改造時の注意点

`std::greater` を指定すると min/max は数値的大小ではなく比較順の両端になります。参照先の要素を削除した後は返された参照を使えません。配列ヒープに置き換える場合、全操作・重複・参照寿命まで再設計が必要です。

## 改造後の確認

空集合への取得は禁止です。1要素、同値多数、両端の交互削除、カスタム比較を確認し、ソート済み配列の先頭末尾と比較します。
