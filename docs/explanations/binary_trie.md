# Binary Trie の実装解説

[使用法に戻る](../binary_trie.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/binary_trie.hpp)

## 目的と基本原理

非負整数を最上位ビットから二分岐させる多重集合です。例えば3ビットの1と6は `001` と `110` で別の根の子へ進みます。数値比較や XOR の最小化では上位ビットが下位すべてより優先するため、上から貪欲に枝を選べます。

## 内部データ

`nodes_` の `next[2]` が子番号、`count` が重複込み部分木要素数です。`xor_all_` は全体 XOR の遅延タグ。保存値は論理値 XOR タグなので、全要素への XOR はタグの変更だけで表現できます。

## 処理の流れと不変条件

`insert/erase/count` は入力をタグで変換して下降します。`kth_element` は論理ビット0となる子の個数を見て順位を分けます。`min_xor_element(x)` は x と一致する上位ビットを優先します。`alive` は子が存在して個数も正であることを確認します。削除でノード自体は解放しません。

## 計算量の根拠

ビット数を $B$ とすると追加・削除・順位・XOR 検索は $O(B)$、全体 XOR は $O(1)$。空間は現在の要素数ではなく、これまで作成した経路に応じて最大 $O(QB)$ です。

## 改造時の注意点

符号付き順序へ変えるなら符号ビットの変換が必要です。`BIT_SIZE` を縮めた場合の範囲制約、最上位ビットのシフト、重複数の int 上限を確認します。`min_xor_element` は要素を返し、`min_xor` は XOR した値を返す点を混同しないでください。

## 改造後の確認

同値を複数追加して1個削除、存在しない値の削除、XOR 後の追加・削除・順位、ビット幅上限の値をソート済み多重集合と比較します。
