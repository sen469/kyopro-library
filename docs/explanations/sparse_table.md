# Sparse Table の実装解説

[使用法に戻る](../sparse_table.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/sparse_table.hpp)

## 目的と基本原理

更新のない配列で区間最小値などを繰り返し求めます。長さが2のべき乗の区間を前計算し、任意の区間を左右2つの区間で覆います。長さ6なら長さ4を両端から取るため中央が重なりますが、最小値なら重複しても答えは変わりません。

## 内部データ

`data_[k][i]` は位置iから長さ $2^k$ の集約、`log_[len]` は床の二進対数です。`data_[0]` が元の配列です。

## 処理の流れと不変条件

構築は隣接する半分の結果を `op` で結合します。`prod(l,r)` は `k=log_[r-l]` を選び、`data_[k][l]` と `data_[k][r-2^k]` を結合します。結合則に加えて冪等性 `op(x,x)=x` が重複区間を無害にします。空区間は `e()` を返します。

## 計算量の根拠

各段に高々N個、段数は $O(\log N)$ なので構築・空間は $O(N\log N)$。取得は2要素を結合するだけで $O(1)$。演算自体が高価ならその費用を掛けます。

## 改造時の注意点

和をそのまま使うと重複区間を二重加算します。非冪等演算には別方式が必要です。点更新を加えると影響する前計算区間が多くなるので、セグメント木との使い分けを検討します。

## 改造後の確認

空配列・空区間・1点・2のべき乗とその前後の長さを確認します。最小値や gcd を全区間の愚直集約と比較します。
