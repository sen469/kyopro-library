# Sieve の実装解説

[使用法に戻る](../sieve.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/sieve.hpp)

## 目的と基本原理

小さい範囲をまとめて扱うふるいと、範囲外の64ビット整数の素数判定・因数分解を組み合わせています。例えば84は最小素因数2で割り、さらに2、3、7へ分解できます。素数個数の計算には別の Lehmer 法を使います。

## 内部データ

`spf_` は最小素因数、`primes_` はふるい内の素数列です。範囲外用には `is_prime_u64`、`pollard_rho`、`factor_u64` を用意します。`prime_counter` は `pi_`、`phi_cache_`、`lehmer_cache_` を独立に保持します。

## 処理の流れと不変条件

線形ふるいではiに対し `p<=spf[i]` の素数だけを掛けることで、合成数を最小素因数から1回だけ生成します。範囲外は Miller–Rabin で $n-1=2^s d$ を使い、固定の底でべき剰余を調べます。合成数なら Pollard rho の2速度の列で差のgcdを取り、非自明な因子が出たら再帰分解します。

`prime_count_less(n)` はn-1以下の素数数です。`phi(x,s)=phi(x,s-1)-phi(x/p_{s-1},s-1)` で小さい素数の倍数を除き、Lehmer の補正ループで残った複合数の数え過ぎを除去します。平方根等は浮動小数点の近似後に整数積で補正します。

## 計算量の根拠

ふるいの時間・空間は $O(N)$、範囲内判定は $O(1)$、分解は $O(\log x)$。64ビット素数判定は固定個数の累乗で $O(\log x)$ の語演算、Pollard rho の試行回数には入力依存性があります。素数計数は初回に500万までの表と1000万要素の long long キャッシュを確保し、以後再利用します。`phi_cache_` だけで約80MBあります。

## 改造時の注意点

64ビット用の底集合を小さくすると判定範囲の保証が変わります。素数計数は全64ビット範囲対応ではなく、使用法の推奨範囲を守ります。内部で $\sqrt{x}$ までの素数を参照するため固定表サイズにも依存します。rho の失敗時再試行、128ビット剰余乗算、因数のソートを省かないでください。

## 改造後の確認

0/1/2の判定、素数冪、二つの大きい素数の積、ふるい境界の前後を確認します。因数の積が元値に戻ること、素数計数の小さい範囲が直接列挙と一致することを確認します。
