# Angular Sort の実装解説

[使用法に戻る](../angular_sort.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/angular_sort.hpp)

## 目的と基本原理

平面ベクトルを原点の周りに反時計回りに並べます。atan2 の角度を作る代わりに、半平面と外積の符号で比較します。角度の切れ目は非零の方向ベクトル `start` で指定し、既定値は正の x 軸 `(1,0)` です。例えば `start=(0,1)` なら `(0,1),(-1,0),(0,-1),(1,0)` の順になります。

## 内部データ

`polar_angle_less` は `angular_sort_options<T>` を保持します。開始方向に加えて、開始方向そのものを先頭側に置くか末尾側に置くか、時計回りか、原点をどう扱うかを保持します。`angular_calc_t` は整数座標なら 128 ビット、浮動小数点なら long double の計算型です。

## 処理の流れと不変条件

まず原点の特別扱いを処理し、次に半平面で比較します。同じ半平面では反時計回りなら `cross(a,b)>0`、時計回りなら `cross(a,b)<0` のとき a を先にします。半平面を分けない外積比較は一周すると循環するためソート用順序になりません。同方向なら、元の点の `norm2` で原点に近い順にします。

半平面は `cross(start,p)` の符号で決めます。外積が 0 の場合、非零ベクトルどうしは平行なので、`start` の非零成分と対応する `p` の成分の符号で同方向と逆方向を区別します。内積や座標の回転を計算せず、余分な大きな積を避けます。開始方向は長さによらず任意で、対象の点に含まれている必要はありません。

回転方向の最初の半周を群 0、残りを群 1 に分類します。開始方向そのものは、
`include_start=true` なら群 0、`false` なら全方向より後の群 2 に入れます。
開始方向の正反対は群 1 です。これにより点を除外せず、回転角の区間を
`[0,2pi)` または `(0,2pi]` に切り替えられます。

原点が `first` / `last` の場合は方向比較の前に先頭 / 末尾へ配置します。
`direction` の場合は方向比較に限って `origin_direction` へ置き換えます。
距離は元の `(0,0)` のままなので、指定方向と同角の非零の点より先になります。
原点を外積 0 の点として全方向と同値にすると比較の同値関係が推移的でなくなるため、
必ず非零の仮想方向を割り当てます。

## 計算量の根拠

比較1回は $O(1)$ なので全体 $O(N\log N)$。インデックス版は元列を変更せずN個の番号をソートし、追加空間 $O(N)$ を使います。

## 改造時の注意点

128ビットでも64ビット座標全域の積の差や平方和が必ず収まるわけではありません。点どうしの外積・平方和に加え、開始方向・原点に割り当てた方向との外積も範囲を確認します。開始方向 `(0,0)` と、`direction` モードでの仮想方向 `(0,0)` は禁止です。浮動小数点比較へ安易に eps を導入すると比較の推移性を壊す場合があります。原点や同方向のタイブレークの意味も維持します。

## 改造後の確認

4軸、原点、開始方向とその反対方向、同方向の距離違い、同値点を確認します。開始方向を全象限で変え、長さだけ変えても順序が同じことを確認します。小さい整数座標では開始方向を基準にした atan2 の角度順と比較し、比較の反対称性・推移性も確認します。

開始方向を含む／含まない、時計回り／反時計回り、原点の3通りのモードと
複数の仮想方向を組み合わせ、同値関係の推移性も確認します。
`(-pi,pi]`・原点の偏角 0 の問題例は専用の期待値でも確認します。
