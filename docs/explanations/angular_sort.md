# Angular Sort の実装解説

[使用法に戻る](../angular_sort.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/angular_sort.hpp)

## 目的と基本原理

平面ベクトルを原点の周りに反時計回りに並べます。atan2 の角度を作る代わりに、半平面と外積の符号で比較します。`(1,0),(0,1),(-1,0),(0,-1)` がこの順になり、角度の切れ目は正のx軸です。

## 内部データ

`angular_half` は原点を-1、上半分と正のx軸を0、残りを1へ分類します。`polar_angle_less` が比較本体、`angular_calc_t` は整数座標なら128ビット、浮動小数点なら long double の計算型です。

## 処理の流れと不変条件

まず半平面で比較し、同じ半平面では `cross(a,b)>0` のときaを先にします。半平面を分けない外積比較は一周すると循環するためソート用順序になりません。同方向なら `norm2` で原点に近い順にします。原点は他のすべてより先です。

## 計算量の根拠

比較1回は $O(1)$ なので全体 $O(N\log N)$。インデックス版は元列を変更せずN個の番号をソートし、追加空間 $O(N)$ を使います。

## 改造時の注意点

128ビットでも64ビット座標全域の積の差や平方和が必ず収まるわけではありません。座標範囲に応じた上界を確認します。浮動小数点比較へ安易に eps を導入すると比較の推移性を壊す場合があります。原点や同方向のタイブレークの意味も維持します。

## 改造後の確認

4軸、原点、反対方向、同方向の距離違い、同値点を確認します。小さい非零座標では角度順と比較し、比較の反対称性・推移性も確認します。
