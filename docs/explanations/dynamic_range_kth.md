# Dynamic Range Kth の実装解説

[使用法に戻る](../dynamic_range_kth.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/dynamic_range_kth.hpp)

## 内部データ

配列位置を Fenwick Tree、各 Fenwick Tree の区間に含まれる値の多重集合を
Binary Trie で管理します。各 Trie ノードは左右の子と要素数を保持します。
符号付き整数は符号ビットを反転して、整数の大小関係をビット列の大小関係へ
変換します。復元時も最小値や最大値を含む符号付き演算のオーバーフローを避けます。

## 更新と区間 Kth

点更新は該当位置を含む Fenwick Tree の $O(\log(n+1))$ 個の Trie から旧値を
削除し、新値を追加します。値の座標圧縮をしないため、未登録の値へ更新できます。

区間 `[l, r)` の要素数は、接頭辞 `[0, r)` の Trie 群の要素数から
接頭辞 `[0, l)` の Trie 群の要素数を引いて求めます。上位ビットから順に、
左の子に含まれる区間要素数が `k` より大きければ左へ進み、そうでなければ
左の子の要素数を `k` から引いて右へ進みます。
同じ下降を全 Trie で同時に行うので、値を二分探索して数え直す必要がありません。

## 計算量とメモリ

値型のビット数を `B` とすると、更新・Kth・個数クエリは $O(B\log(n+1))$ です。
配列の各要素が $O(\log(n+1))$ 個の Trie に最大 `B+1` ノードを必要とするため、
構築時間・最悪空間は $O(nB\log(n+1))$ です。共通するビット接頭辞はノードを共有します。
要素数が 0 になった枝は下から外し、不要ノードを再利用リストへ戻すので、
過去に更新した値の種類数だけメモリが増え続けることはありません。

## 確認方法

更新後の部分配列をソートして全順位と比較し、頻度は直接カウントします。
負数、重複、符号付き・符号なし整数の端点、空区間、同値への更新、
繰り返しの更新、コピー後の独立性、再構築を検証します。
