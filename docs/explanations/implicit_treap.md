# Implicit Treap の実装解説

[使用法に戻る](../implicit_treap.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/implicit_treap.hpp)

## 目的と基本原理

途中への挿入・削除や区間反転がある列を扱います。配列で要素をずらす代わりに、列を二分木の中順走査として表します。例えば `[a,b,c,d]` を2要素で分割すると `[a,b]` と `[c,d]` になり、木の接続だけで再結合できます。

## 内部データ

`node` の `val` は1要素、`size` は部分木の要素数、`priority` は xorshift で生成する優先度です。`prod/rprod` は順方向/逆方向の集約、`lazy` と `lazy_flag` は未伝播の作用、`rev` は反転予約です。

## 処理の流れと不変条件

`split(t,k)` は左部分木のサイズで分岐し、先頭k要素と残りに分けます。`merge` は小さい優先度を根に選びます。区間操作は2回の分割で対象を独立させ、作用後に結合します。`all_reverse` は左右と `prod/rprod` を交換し、子への反転は `push` まで遅らせます。下降前の `push`、接続変更後の `update` により列順と集約が一致します。

## 計算量の根拠

ランダム優先度を仮定すると高さは期待 $O(\log N)$。点操作・区間集約・遅延作用・反転は期待 $O(\log N)$、区間削除はさらに削除要素数が必要です。初期配列は順次挿入するため期待 $O(N\log N)$。コピーと列挙は $O(N)$、空間 $O(N)$ です。

## 改造時の注意点

`composition(f,g)` は g の後に f を作用させる順です。和への区間加算なら `S` に要素数を入れて `mapping` で加算量を掛けます。逆方向集約も更新しないと非可換演算の反転が壊れます。位置依存の作用は現在の一様な `mapping` だけでは表せません。`move` の挿入位置は切り出し後の列に対する位置です。

## 改造後の確認

vector と比較し、挿入→反転→作用→削除を交互に実施します。文字列連結や行列積で順序を確認し、空区間、全反転、コピー後の変更も確認します。
