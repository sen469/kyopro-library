# Binary Search の実装解説

[使用法に戻る](../binary_search.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/binary_search.hpp)

## 目的と基本原理

整数半開区間で、偽から真へ一度だけ切り替わる述語の最初の真を探します。`[0,10)` で `x>=6` なら6、全偽なら10です。毎回調べる範囲を半分にすることで線形走査を減らします。

## 内部データ

状態は `first,last` と `middle` だけです。`search_distance` は符号なし型で距離を表し、`search_advance` は整数範囲の端も扱って位置を進めます。

## 処理の流れと不変条件

中央が真なら最初の真は中央以前なので `last=middle`。偽なら中央までは候補でなく `first=middle+1`。区間外の初期 `last` は一度も評価せず、見つからない場合の返り値として残します。候補を除外しない不変条件と区間の縮小で正しく終了します。

## 計算量の根拠

幅Wの区間で述語呼び出しは $O(\log(W+1))$、補助空間は $O(1)$。述語が $O(F)$ なら時間はその積です。

## 改造時の注意点

真→偽の判定は否定などで向きを揃えます。`(first+last)/2` に戻すと符号付き端であふれるため、補助関数の意味を維持します。最大整数を候補に含める際は半開区間の右端を表せるか確認します。

## 改造後の確認

空、全偽、全真、先頭だけ偽、末尾だけ真、符号付き最小値から最大値までの区間を確認します。小区間は全探索と比較します。
