# Dijkstra の実装解説

[使用法に戻る](../dijkstra.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/dijkstra.hpp)

## 目的と基本原理

非負重みのグラフで始点からの最短距離を求めます。未確定の最小距離を優先キューで選ぶことで、全頂点を毎回探す処理を減らします。例えば辺 `0→1:5, 0→2:1, 2→1:2` なら頂点1の距離は最初5、その後3へ改善されます。

## 内部データ

`dist` は現在の最良距離、`prev` はその経路の直前頂点、`que` は `(距離,頂点)` の最小ヒープです。結果の `inf` は到達不能の判定にも使います。

## 処理の流れと不変条件

始点を距離0で登録し、キューから取り出した距離が現在の `dist[v]` と違えば古い情報として捨てます。そうでなければ隣接辺を緩和し、改善した頂点だけ再登録します。非負重みなので、取り出した最小候補を後からより短くする経路はありません。`path` は `prev` を逆にたどって反転します。

## 計算量の根拠

頂点数N・辺数Mとして空間 $O(N+M)$、この重複登録型ヒープの時間の上界は $O(N+M\log(M+1))$。単純グラフでは通常 $O((N+M)\log N)$ と表せます。経路復元は経路長に比例します。

## 改造時の注意点

負辺には使えません。`d+cost` を計算してから比較するので、加算のオーバーフローと `inf` 以上の実距離に注意します。等距離では `prev` を更新しないため辞書順最小経路などは保証しません。多始点化は各始点を0でキューへ入れる変更が必要です。

## 改造後の確認

遠回りが後で改善される例、孤立点、重複辺、0重み、始点自身を確認します。小さいグラフの全点対最短路と比較します。
