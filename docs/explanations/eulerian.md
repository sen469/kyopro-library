# Eulerian Path / Cycle の実装解説

[使用法に戻る](../eulerian.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/eulerian.hpp)

## 始点と次数条件

有向の閉路では全頂点の入次数と出次数が一致する必要があります。
閉じない路では、出次数が入次数より1大きい始点と、入次数が出次数より1大きい終点が
それぞれ1頂点あり、残りの頂点は入出次数が一致します。

無向では奇数次数の頂点が0個なら閉路、2個ならその2頂点を両端とする路の候補です。
自己ループは隣接リストに同じ辺 ID で2回登録し、次数に2を加えます。
指定始点が次数条件に合わない場合は探索前に失敗を返します。
始点を省略した場合は、必要な始点があればそれを、なければ辺を持つ頂点を選びます。

## Hierholzer 法と復元

各頂点の未処理の隣接辺位置を `next`、各辺の使用状態を `used` に持ちます。
始点から未使用の辺を順にたどり、移動先の頂点と使用した辺 ID をスタックへ積みます。
進めなくなった頂点はスタックから取り出し、結果へ追加します。
この逆順の記録により、途中の頂点から伸びた閉路も1つの路へつなげられます。
最後に頂点列と辺 ID 列をそれぞれ反転します。

無向辺は両方向の隣接要素が同じ ID を持つため、一方を使うと他方も使用済みになります。
多重辺は異なる ID を持つので区別できます。
探索後に使用した辺の数が `m` と一致しなければ、辺を持つ別成分が残っているため失敗です。
これにより、孤立点を無視しつつ全辺を通ったことを確認できます。

## 計算量と確認方法

各隣接要素は1回ずつ処理し、各辺は1回だけ使用します。
次数確認、探索、反転を含め、時間・追加空間ともに $O(n+m)$ です。
明示的なスタックを使うため、長い路でも再帰スタックを消費しません。

小規模グラフでは未使用辺を全探索し、有向・無向、始点指定、路・閉路の存在を比較します。
返された各辺 ID が1回ずつ現れ、対応する頂点間を正しい向きで接続することも確認します。
自己ループ、多重辺、次数条件は満たすが非連結なグラフ、孤立点、辺0本と空グラフを検証します。
