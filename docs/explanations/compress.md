# Coordinate Compression の実装解説

[使用法に戻る](../compress.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/compress.hpp)

## 目的と基本原理

値の大小関係だけを小さな連番へ置き換えます。`[100,-5,100,9]` はソート済みの異なる値 `[-5,9,100]` を使って `[2,0,2,1]` になります。巨大な値を配列添字として扱えます。

## 内部データ

`compressor` の `xs` は登録値、`built` はソート・重複除去済みかを表します。`compress_result` は各要素の番号 `compressed` と逆変換用 `values` を返します。

## 処理の流れと不変条件

`add` は末尾へ追加して未構築にし、`build` で sort と unique を行います。`get` は `lower_bound` の位置なので、未登録値でも挿入位置を返します。例えば上の集合で `get(8)=1` ですが、8が登録されている意味ではありません。

## 計算量の根拠

登録数Nについて構築 $O(N\log N)$、各番号取得 $O(\log N)$、空間 $O(N)$。配列全体の `compress` は全要素に二分探索するため $O(N\log N)$ です。

## 改造時の注意点

圧縮は大小関係を保ちますが差・距離は保ちません。区間長が必要なら元の値で差を取ります。追加後の再構築で既存番号も変わるため、番号を別構造へ渡した後の追加には注意します。比較と等値の整合した型を使用します。

## 改造後の確認

負数、全同値、空、未登録値の上下界、再構築後の番号を確認します。`values[compressed[i]]` が元値と一致するか検査します。
