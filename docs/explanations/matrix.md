# Matrix の実装解説

[使用法に戻る](../matrix.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/matrix.hpp)

## 目的と基本原理

行列は線形変換を表し、その積は変換の合成です。列ベクトルにA、次にBを作用させるなら全体はBAです。例えばフィボナッチ遷移行列を累乗すると、1段ずつ遷移する代わりに対数回の行列積で先の状態へ進めます。

## 内部データ

`data_` は行ごとの vector、`width_` は列数です。0行でも指定した列数を保持し、方程式が0本・変数がW個の連立方程式も表せます。空の二次元配列から構築した場合は列数0です。`identity` は対角に1、他を既定構築値で埋めます。

## 処理の流れと不変条件

積は i,k,j の3重ループで `res[i][j] += lhs[i][k]*rhs[k][j]` を計算します。各kの寄与を足すことで行と列の内積になります。`pow` は指数のビットを読み、立っている箇所だけ累積行列へ掛け、毎段 base を二乗します。指数0なら単位行列です。

## 行列式・逆行列・ランク

3関数は元の行列をコピーし、共通の `eliminate` で行基本変形します。左から列を調べ、未使用の行から非零のピボットを選びます。必要なら行を交換し、`T(1) / pivot` で求めた逆元を掛けてピボットを1にします。行列式・ランクでは下の行、逆行列では自分以外の全行からその列の成分を消します。

ピボットのある列だけ行番号を進めるため、零の列が途中にあっても処理できます。ピボット数がランクです。ピボットのない列は飛ばし、以後の行にはその列の非零成分がないことを保ちます。

`determinant` は行交換ごとに符号を反転し、正規化前のピボットを掛け合わせます。他の行の定数倍を引く操作は行列式を変えません。ピボット数が行数より少なければ行列式は0です。0行0列では空積として1を返します。

`inverse` は単位行列にも同じ行基本変形を施します。入力側が単位行列になれば、同伴行列が逆行列です。ピボット数が行数に達しなければ `std::nullopt` を返します。

## 一次連立方程式

`solve(b)` は係数行列のコピーと右辺の1列行列に同じ行基本変形を施します。`eliminate` はピボット列も記録し、右辺を同伴行列として渡す場合は上側の行も消去します。係数の列だけをピボット候補とし、右辺の列は候補に含めません。

ランクR以降の行は係数がすべて0です。その右辺に非零要素があれば矛盾するため、`exists = false` を返します。それ以外では各ピボット列が従属変数、残りの列が自由変数です。

自由変数をすべて0にすると、ピボット変数に変形後の右辺を入れた特殊解になります。自由変数の列jごとに、その変数だけを1にし、ピボット変数を `-work[i][j]` にしたベクトルを基底として返します。自由変数部分が標準基底なので、返すベクトルは線形独立であり、すべての同次解を生成します。基底の本数はW-Rです。

方程式が0本の場合はすべての変数が自由です。変数が0個の場合は右辺がすべて0のときだけ解が存在します。

要素型の演算は型へ委譲します。ACLのmodintでは `/` が `inv()` を呼ぶので、逆元の計算を別途実装する必要はありません。ただし非零のピボットがすべて可逆である体が前提です。合成数の法では、可逆な行列でも選んだピボットに逆元がない場合があるため対象外です。

## 計算量の根拠

H×K と K×W の積は $O(HKW)$、結果空間 $O(HW)$。N次正方行列の累乗は $O(N^3\log e)$、作業空間 $O(N^2)$。要素型の演算を定数時間とした評価です。

行基本変形では高々 $\min(H,W)$ 個のピボットに対し、各 $O(HW)$ の演算を行います。ランクは $O(HW\min(H,W))$、行列式・逆行列は $O(N^3)$ です。コピーを含む追加空間は $O(HW)$、正方行列なら $O(N^2)$ です。逆元計算はピボットごとに1回です。

連立方程式は同じ消去処理に加え、特殊解とD=W-R本の長さWの基底を構築します。時間は $O(HW\min(H,W)+H+W+WD)$、返り値を含む追加空間は $O(HW+H+W+WD)$ です。零行列では基底の出力だけで $O(W^2)$ を要します。

## 改造時の注意点

要素型の既定値が加法の0である必要があります。modint の利用なら法演算を型へ任せられますが、通常整数なら積と和の桁あふれを確認します。min-plus 等へ変更するなら加算・乗算だけでなくゼロと単位行列の定義をすべて変えます。行を外から resize すると長方形の不変条件を壊せます。

行基本変形の零判定は `== T(0)` です。整数の切り捨て除算や浮動小数点の誤差を扱わないため、行列式・逆行列・ランク・連立方程式ではこれらの組み込み型を `static_assert` で拒否します。実数へ対応させる場合は、零判定の許容誤差と絶対値によるピボット選択を併せて設計してください。

## 改造後の確認

非正方形の積、単位行列、指数0/1、0行、次元不一致、自己乗算を確認します。小さい指数は逐次積と比較します。

行基本変形では、行交換・零の先頭列・特異行列・長方形・空行列を確認します。小さい素数の法で2行2列の行列を全列挙し、直接計算した行列式と比較します。逆行列がある場合は左右両方から掛けて単位行列になること、各操作で元の行列が変わらないことも確認します。

連立方程式では、一意解・自由変数・矛盾・0本の方程式・0個の変数を確認します。法2の小さい行列と右辺を全列挙し、変数の全列挙で求めた解集合と、特殊解に基底の線形結合を加えた集合が一致することを確認します。生成された集合の大きさも調べ、基底の独立性を確認します。
