# Matrix の実装解説

[使用法に戻る](../matrix.md) / [実装](https://github.com/sen469/kyopro-library/blob/main/lib/kyopro/matrix.hpp)

## 目的と基本原理

行列は線形変換を表し、その積は変換の合成です。列ベクトルにA、次にBを作用させるなら全体はBAです。例えばフィボナッチ遷移行列を累乗すると、1段ずつ遷移する代わりに対数回の行列積で先の状態へ進めます。

## 内部データ

`data_` は行ごとの vector です。`identity` は対角に1、他を既定構築値で埋めます。独立した列数メンバはなく、0行の場合の幅は0と見なされます。

## 処理の流れと不変条件

積は i,k,j の3重ループで `res[i][j] += lhs[i][k]*rhs[k][j]` を計算します。各kの寄与を足すことで行と列の内積になります。`pow` は指数のビットを読み、立っている箇所だけ累積行列へ掛け、毎段 base を二乗します。指数0なら単位行列です。

## 計算量の根拠

H×K と K×W の積は $O(HKW)$、結果空間 $O(HW)$。N次正方行列の累乗は $O(N^3\log e)$、作業空間 $O(N^2)$。要素型の演算を定数時間とした評価です。

## 改造時の注意点

要素型の既定値が加法の0である必要があります。modint の利用なら法演算を型へ任せられますが、通常整数なら積と和の桁あふれを確認します。min-plus 等へ変更するなら加算・乗算だけでなくゼロと単位行列の定義をすべて変えます。行を外から resize すると長方形の不変条件を壊せます。

## 改造後の確認

非正方形の積、単位行列、指数0/1、0行、次元不一致、自己乗算を確認します。小さい指数は逐次積と比較します。
